# PHP Array Practice Problems

## Problem 1: Basic Array Operations
Create a PHP script that:

1. Create an indexed array called `$fruits` with three items: "Apple", "Orange", and "Banana"

2. Display the first item in the array

3. Change the last item to "Grape"

4. Add "Mango" to the end of the array

5. Display the total number of items using `count()`

6. Loop through the array using `foreach` and display each fruit on a new line

**Expected output:**
```
First fruit: Apple
Total items: 4
Apple
Orange
Grape
Mango
```

**Hint:** Remember that arrays start at index 0, and you can use `$fruits[] = "value"` to add to the end!

## Problem 2: Working with Associative Arrays
Create a PHP script that:

1. Create an associative array called `$student` with the following key-value pairs:
   - "name" => "John Doe"
   - "age" => 20
   - "grade" => "A"
   - "city" => "New York"

2. Display the student's name and grade

3. Update the student's age to 21

4. Add a new key "email" with value "john@example.com"

5. Loop through the array using `foreach` and display each key-value pair in the format: "key: value"

6. Check if the key "phone" exists in the array. If it doesn't, display "Phone number not available"

**Expected output:**
```
Student: John Doe
Grade: A
name: John Doe
age: 21
grade: A
city: New York
email: john@example.com
Phone number not available
```

**Hint:** Use `array_key_exists()` or `isset()` to check if a key exists in an associative array!

## Problem 3: Multidimensional Array and Calculations
Create a PHP script that:

1. Create a multidimensional array called `$students` containing information about 3 students:
   ```php
   [
       ["name" => "Alice", "scores" => [85, 90, 88]],
       ["name" => "Bob", "scores" => [78, 82, 80]],
       ["name" => "Charlie", "scores" => [92, 95, 90]]
   ]
   ```

2. Loop through each student and:
   - Display the student's name
   - Calculate their average score (sum of scores divided by number of scores)
   - Display the average rounded to 2 decimal places
   - Display all their individual scores

3. Find and display the student with the highest average score

**Expected output:**
```
Student: Alice
Average: 87.67
Scores: 85, 90, 88

Student: Bob
Average: 80.00
Scores: 78, 82, 80

Student: Charlie
Average: 92.33
Scores: 92, 95, 90

Highest average: Charlie with 92.33
```

**Hint:** Use `array_sum()` to sum the scores array, `count()` to get the number of scores, and `round()` to format the average. Keep track of the highest average as you loop!

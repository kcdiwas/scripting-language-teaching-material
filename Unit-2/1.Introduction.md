# Introduction to Server-Side Scripting with PHP

PHP (PHP: Hypertext Preprocessor) is a popular server-side scripting language used to create dynamic web pages. Unlike JavaScript which runs in the browser, PHP runs on the web server before the page is sent to the user's browser.

## What is Server-Side Scripting?

When you visit a website, here's what happens:

1. **Your browser** sends a request to the **web server**
2. The **web server** runs PHP code to generate HTML
3. The **server** sends the final HTML back to your browser
4. Your **browser** displays the page


**Client-Side (JavaScript):**
- Runs in the user's browser
- Can see the code in browser's developer tools
- Limited access to server resources
- Examples: Form validation, animations, DOM manipulation

**Server-Side (PHP):**
- Runs on the web server
- Code is hidden from users
- Full access to databases, files, server resources
- Examples: User authentication, database queries, file processing

For exam purposes: PHP runs on the server, JavaScript runs in the browser!

## What is PHP?

PHP stands for **PHP: Hypertext Preprocessor** (it's a recursive acronym). It's:

- **Free and open-source** - No cost to use
- **Cross-platform** - Works on Windows, Linux, macOS
- **Easy to learn** - Similar syntax to C, Java, and JavaScript
- **Widely used** - Powers millions of websites including Facebook, WordPress, Wikipedia
- **Embedded in HTML** - PHP code can be mixed with HTML

### Why Use PHP?

PHP is commonly used for:
- **Dynamic websites** - Pages that change based on user input
- **Database interactions** - Connecting to MySQL, PostgreSQL, etc.
- **Form processing** - Handling form submissions
- **User authentication** - Login systems
- **Content management** - Building CMS like WordPress
- **E-commerce** - Shopping carts, payment processing

## How PHP Works

Here's a simple example of how PHP works:

```php
<!DOCTYPE html>
<html>
<head>
    <title>My First PHP Page</title>
</head>
<body>
    <h1>Hello from PHP!</h1>
    <?php
        echo "Today is " . date("Y-m-d");
    ?>
</body>
</html>
```

**What happens:**
1. Server receives request for this file
2. PHP engine processes the `<?php ... ?>` code
3. `echo` outputs text
4. `date()` gets current date
5. Server sends final HTML to browser

**Browser receives:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>My First PHP Page</title>
</head>
<body>
    <h1>Hello from PHP!</h1>
    Today is 2024-01-15
</body>
</html>
```

## PHP Syntax Basics

### PHP Tags

PHP code must be enclosed in special tags:

```php
<?php
    // PHP code goes here
?>
```

```warn header="PHP tags are required"
PHP code must be inside `<?php ... ?>` tags. Without these tags, the server will treat your code as plain text and send it to the browser as-is.

**Correct:**
```php
<?php
    echo "Hello";
?>
```

**Wrong:**
```php
echo "Hello"; // This will be sent as plain text!
```
```

### Comments

PHP supports three types of comments:

<?php
    // Single-line comment
    
    # Another single-line comment
    
    /*
     * Multi-line comment
     * Can span multiple lines
     */
?>
```

### Outputting Text

The most common way to output text in PHP is using `echo`:

```php
<?php
    echo "Hello, World!";
    echo "This is PHP";
?>
```

You can also use `print` (similar to `echo`):

```php
<?php
    print "Hello, World!";
?>
```

Both `echo` and `print` output text, but there are small differences:

- `echo` - Can output multiple values, slightly faster
- `print` - Returns 1 (can be used in expressions), slightly slower

For most purposes, they're interchangeable. `echo` is more commonly used.

## Variables in PHP

Variables in PHP start with a `$` sign:

```php
<?php
    $name = "John";
    $age = 25;
    $price = 99.99;
    $isActive = true;
    
    echo "Name: " . $name;
    echo "Age: " . $age;
?>
```

### Variable Rules

- Must start with `$` followed by letter or underscore
- Can contain letters, numbers, and underscores
- Case-sensitive (`$name` and `$Name` are different)
- No need to declare type (PHP is loosely typed)

```php
<?php
    $username = "john_doe";  // Valid
    $user_name = "jane";     // Valid
    $_temp = "temp";         // Valid
    $123invalid = "test";    // Invalid (starts with number)
    $user-name = "test";     // Invalid (contains hyphen)
?>
```

### Variable Types

PHP automatically determines the type:

```php
<?php
    $string = "Hello";        // String
    $integer = 42;            // Integer
    $float = 3.14;            // Float
    $boolean = true;           // Boolean
    $array = [1, 2, 3];       // Array
    $null = null;             // Null
?>
```

## Strings in PHP

Strings can be created with single or double quotes:

```php
<?php
    $single = 'Hello World';
    $double = "Hello World";
    
    echo $single;
    echo $double;
?>
```

### String Concatenation

Use `.` (dot) to join strings:

```php
<?php
    $firstName = "John";
    $lastName = "Doe";
    
    $fullName = $firstName . " " . $lastName;
    echo $fullName; // Output: John Doe
    
    // Or use echo directly
    echo $firstName . " " . $lastName;
?>
```

### Double Quotes vs Single Quotes

Double quotes allow variable interpolation:

```php
<?php
    $name = "John";
    
    // Double quotes - variables are replaced
    echo "Hello $name";  // Output: Hello John
    
    // Single quotes - treated as literal text
    echo 'Hello $name';  // Output: Hello $name
?>
```

## Basic PHP Example

Here's a complete PHP page:

```php
<!DOCTYPE html>
<html>
<head>
    <title>PHP Example</title>
</head>
<body>
    <h1>Welcome</h1>
    
    <?php
        // Variables
        $username = "John";
        $visits = 5;
        
        // Output
        echo "<p>Hello, " . $username . "!</p>";
        echo "<p>You have visited " . $visits . " times.</p>";
        
        // Date
        echo "<p>Today is " . date("l, F j, Y") . "</p>";
    ?>
</body>
</html>
```

**Browser sees:**
```html
<!DOCTYPE html>
<html>
<head>
    <title>PHP Example</title>
</head>
<body>
    <h1>Welcome</h1>
    <p>Hello, John!</p>
    <p>You have visited 5 times.</p>
    <p>Today is Monday, January 15, 2024</p>
</body>
</html>
```

### Mixing PHP and HTML

You can mix PHP and HTML freely:

```php
<!DOCTYPE html>
<html>
<head>
    <title><?php echo "My Page"; ?></title>
</head>
<body>
    <?php
        $pageTitle = "Welcome";
    ?>
    <h1><?php echo $pageTitle; ?></h1>
    
    <p>This is regular HTML.</p>
    
    <?php
        if ($loggedIn) {
            echo "<p>You are logged in.</p>";
        }
    ?>
</body>
</html>
```

## Setting Up PHP

To run PHP, you need:

1. **Web Server** - Apache, Nginx, or built-in PHP server
2. **PHP Engine** - PHP interpreter installed
3. **Text Editor** - To write PHP code

### Using Built-in PHP Server (Development)

For learning, you can use PHP's built-in server:

```bash
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.

### Common PHP Setup

- **XAMPP** - Apache + MySQL + PHP (Windows, Mac, Linux)
- **WAMP** - Windows + Apache + MySQL + PHP
- **MAMP** - Mac + Apache + MySQL + PHP
- **LAMP** - Linux + Apache + MySQL + PHP

## Common PHP Functions

PHP has many built-in functions:

```php
<?php
    // String functions
    echo strlen("Hello");           // 5 (length)
    echo strtoupper("hello");       // HELLO
    echo strtolower("HELLO");      // hello
    echo substr("Hello", 0, 3);    // Hel
    
    // Number functions
    echo abs(-5);                   // 5
    echo round(3.7);                 // 4
    echo rand(1, 10);                // Random number 1-10
    
    // Date functions
    echo date("Y-m-d");             // 2024-01-15
    echo date("H:i:s");             // 14:30:45 (time)
    
    // Array functions
    $arr = [1, 2, 3];
    echo count($arr);                // 3
?>
```

## PHP vs JavaScript

Here's a quick comparison:

| Feature | PHP | JavaScript |
|---------|-----|-------------|
| **Runs on** | Server | Browser/Server |
| **File extension** | `.php` | `.js` |
| **Variables** | `$variable` | `let variable` |
| **String concat** | `.` (dot) | `+` (plus) |
| **Output** | `echo` | `console.log()` |
| **Comments** | `//` or `#` | `//` |
| **Code tags** | `<?php ?>` | `<script></script>` |

```php
<?php
    // PHP example
    $name = "John";
    echo "Hello " . $name;
?>
```

```javascript
// JavaScript example
let name = "John";
console.log("Hello " + name);
```

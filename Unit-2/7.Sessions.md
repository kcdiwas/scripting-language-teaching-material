#  PHP Notes: Sessions and Cookies

### **The Problem: "Stateless" HTTP**

Before we dive in, remember this: The web (HTTP) is **stateless**. This means the server treats every request as a completely new one. It doesn't remember who you are from page to page.

  * **Analogy:** It’s like meeting a person with short-term memory loss. Every time you speak to them, you have to re-introduce yourself.

**Solution:** To "remember" users (e.g., keeping them logged in or remembering their shopping cart), we use **Cookies** and **Sessions**.

-----

## 1\. PHP Cookies 

### **What is a Cookie?**

A cookie is a small text file stored on the **User's Computer (Client-side)**. The browser sends this file back to the server with every page request.

  * **Location:** Client’s Browser.
  * **Capacity:** Small (approx 4KB).
  * **Security:** Less secure (users can modify them).
  * **Use Case:** Remembering non-sensitive data like "Dark Mode" preference, "Remember Me" username, or language settings.


### **How to Set a Cookie**

We use the `setcookie()` function.
**Important Rule:** This function must be called **before** any HTML output (before `<html>`, spaces, or echo statements).

**Syntax:**

```php
setcookie(name, value, expire, path, domain, secure, httponly);
```

*(For exams, focus on the first three parameters).*

**Example: Creating a Cookie**

```php
<?php
// Set a cookie named "user_name" with value "JohnDoe"
// It expires in 1 hour (3600 seconds)
setcookie("user_name", "JohnDoe", time() + 3600, "/");
?>
```

### **How to Read a Cookie**

We use the global array `$_COOKIE`.

**Example: Retrieving a Cookie**

```php
<?php
if(isset($_COOKIE["user_name"])) {
    echo "Welcome back, " . $_COOKIE["user_name"];
} else {
    echo "Welcome, guest!";
}
?>
```

### **How to Delete a Cookie**

To delete a cookie, you set its expiration date to a time in the **past**.

**Example: Deleting a Cookie**

```php
<?php
// Set expiration time to 1 hour ago (time() - 3600)
setcookie("user_name", "", time() - 3600, "/");
echo "Cookie has been deleted.";
?>
```

## 2\. PHP Sessions 

### **What is a Session?**

A session is a way to store information (in variables) to be used across multiple pages. Unlike cookies, the information is not stored on the user's computer.

  * **Location:** Server-side.
  * **Capacity:** Unlimited (depends on server space).
  * **Security:** More secure (data stays on the server).
  * **Use Case:** User logins, sensitive data, banking apps, shopping carts.

**How it works:** The server creates a unique **Session ID** (a random string) for the user. This ID is usually stored in a temporary cookie on the user's browser, while the actual data sits safely on the server.

### **Starting a Session**

Every page that uses session variables must start with this function:

```php
session_start();
```

**Important Rule:** Just like cookies, `session_start()` must be at the very top of your file, before any HTML.

### **Storing and Reading Session Data**

We use the global array `$_SESSION`.

**Example: Setting Session Variables (page1.php)**

```php
<?php
session_start(); // Start the session

$_SESSION["username"] = "Student123";
$_SESSION["role"] = "Admin";

echo "Session variables are set.";
?>
```

**Example: Reading Session Variables (page2.php)**

```php
<?php
session_start(); // Resume the session

echo "Logged in as: " . $_SESSION["username"];
// Output: Logged in as: Student123
?>
```

### **Destroying a Session (Logout)**

To remove all global session variables and destroy the session (commonly used for "Log Out").

```php
<?php
session_start();

// 1. Remove all session variables
session_unset();

// 2. Destroy the session
session_destroy(); 

echo "You have been logged out.";
?>
```

## 3\. Quick Comparison (Cheat Sheet)

| Feature | Cookie  | Session  |
| :--- | :--- | :--- |
| **Storage Location** | User's Browser (Client-side) | Web Server (Server-side) |
| **Security** | Low (Text file can be read/edited) | High (Stored on server) |
| **Data Limit** | Approx 4KB | Unlimited (Server limit) |
| **Expiration** | Set manually by code | Ends when browser closes (default) |
| **Best For** | User preferences (Themes, Language) | Sensitive data (Login ID, Cart) |

-----

## 4\. Exam "Gotchas" (Don't forget these\!)

1.  **Placement:** `setcookie()` and `session_start()` must be the **very first lines** of code. If you have a blank space or an HTML tag before them, you will get an error: *"Headers already sent"*.
2.  **Availability:**
      * **Cookies:** Once set, a cookie is not available until the *next* page load. You cannot set it and read it immediately on the same page load.
      * **Sessions:** Available immediately after setting them.
3.  **Arrays:** Both `$_COOKIE` and `$_SESSION` are **Associative Arrays**. You access them using keys (strings), e.g., `$_SESSION['key']`.

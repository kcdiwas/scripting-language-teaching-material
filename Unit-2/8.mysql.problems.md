### **Problem 1: The "Simple Login" (Beginner)**

**Topic:** Connections, SELECT, WHERE, $\_POST, Sessions

**Scenario:**
You are building a login page. You have a database named `school_db` and a table named `users` with columns: `id`, `username`, `password`.

**Tasks:**

1.  Write the SQL query to find a user where the `username` is "student1" and `password` is "pass123".
2.  Write a PHP script that:
      * Connects to the database.
      * Checks if the username and password submitted via a form exist in the database.
      * If a match is found, start a **Session** and save the username in `$_SESSION['user']`.
      * If not found, echo "Invalid Login".

\<details\>
\<summary\>\<strong\>Click to see Solution\</strong\>\</summary\>

**SQL:**

```sql
SELECT * FROM users WHERE username = 'student1' AND password = 'pass123';
```

**PHP:**

```php
<?php
session_start();
$conn = mysqli_connect("localhost", "root", "", "school_db");

$u = $_POST['username'];
$p = $_POST['password'];

$sql = "SELECT * FROM users WHERE username='$u' AND password='$p'";
$result = mysqli_query($conn, $sql);

if (mysqli_num_rows($result) > 0) {
    $_SESSION['user'] = $u;
    echo "Login Successful!";
} else {
    echo "Invalid Login";
}
?>
```

### **Problem 2: The "Class Report" (Intermediate)**

**Topic:** Aggregate Functions, GROUP BY, ORDER BY, Formatting

**Scenario:**
You have a table `exam_results` with columns: `student_name`, `subject`, and `marks`. You need to generate a report showing the average score for each subject.

**Tasks:**

1.  Write an SQL query that lists the `subject` and the `Average Score` for that subject.
2.  Group the results by subject.
3.  Sort the results so the subject with the highest average score is at the top.
4.  Write the PHP code to display this in a simple HTML table.

\<details\>
\<summary\>\<strong\>Click to see Solution\</strong\>\</summary\>

**SQL:**

```sql
SELECT subject, AVG(marks) as avg_score 
FROM exam_results 
GROUP BY subject 
ORDER BY avg_score DESC;
```

**PHP:**

```php
<?php
$conn = mysqli_connect("localhost", "root", "", "school_db");
$sql = "SELECT subject, AVG(marks) as avg_score FROM exam_results GROUP BY subject ORDER BY avg_score DESC";
$result = mysqli_query($conn, $sql);

echo "<table border='1'>";
echo "<tr><th>Subject</th><th>Average Score</th></tr>";

while($row = mysqli_fetch_assoc($result)) {
    echo "<tr>";
    echo "<td>" . $row['subject'] . "</td>";
    echo "<td>" . round($row['avg_score'], 2) . "</td>"; // rounding for neatness
    echo "</tr>";
}
echo "</table>";
?>
```

\</details\>

### **Problem 3: The "Product Filter" (Advanced)**

**Topic:** JOINS, Subqueries, Logic

**Scenario:**
You are running an electronics store.

  * **Table `products`**: `id`, `name`, `price`, `category_id`
  * **Table `categories`**: `id`, `cat_name` (e.g., Laptops, Phones)

**Tasks:**

1.  **The Join:** Write an SQL query that displays the **Product Name** and its **Category Name** using an `INNER JOIN`.
2.  **The Subquery:** Write an SQL query to select all products that are **more expensive** than the average price of all products in the store.
3.  **The Logic:** Explain briefly (in text) why we would use a `LEFT JOIN` instead of an `INNER JOIN` if we added a new product but haven't assigned it a category yet.

\<details\>
\<summary\>\<strong\>Click to see Solution\</strong\>\</summary\>

**1. JOIN SQL:**

```sql
SELECT products.name, categories.cat_name
FROM products
INNER JOIN categories ON products.category_id = categories.id;
```

**2. Subquery SQL:**

```sql
SELECT * FROM products 
WHERE price > (SELECT AVG(price) FROM products);
```

**3. Logic Answer:**
We would use a **LEFT JOIN** because an INNER JOIN only returns rows where there is a match in *both* tables. If a product has no category (or a category ID that doesn't exist in the categories table), an INNER JOIN would hide that product from the list. A LEFT JOIN ensures the product is still listed, even if the category name appears as NULL.

\</details\>

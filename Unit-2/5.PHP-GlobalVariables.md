# PHP Global Variables

PHP has several built-in global variables called "superglobals". These are special arrays that are always available everywhere in your code, without needing to declare them as global.

## What are Superglobals?

Superglobals are built-in variables that give you access to important information like:
* User form data
* Server information
* Session data
* Cookie data
* File uploads
* And more!

They're called "super" because they're available in all scopes (inside functions, classes, everywhere).

## The Main Superglobals

Here are the most important PHP superglobals:

* `$_GET` - URL parameters
* `$_POST` - Form data (POST method)
* `$_REQUEST` - Both GET and POST data
* `$_SERVER` - Server and request information
* `$_SESSION` - Session variables
* `$_COOKIE` - Cookie data
* `$_FILES` - Uploaded files
* `$_ENV` - Environment variables
* `$GLOBALS` - All global variables

Let's explore each one!

## $_GET - URL Parameters

Contains data sent through URL query strings.

**Example URL:** `page.php?name=Alice&age=25`

```php
<?php
// Access URL parameters
$name = $_GET['name'];  // Alice
$age = $_GET['age'];    // 25

echo "Name: " . $name . "<br>";
echo "Age: " . $age;
?>
```

**Check if parameter exists:**
```php
<?php
if (isset($_GET['name'])) {
  echo "Name: " . $_GET['name'];
} else {
  echo "No name provided";
}
?>
```

**Common uses:**
* Search queries
* Page filtering
* Product IDs
* Pagination

**Security note:** Always sanitize $_GET data!
```php
<?php
$search = htmlspecialchars($_GET['search']);
echo "You searched for: " . $search;
?>
```

## $_POST - Form Data

Contains data sent through HTML forms using POST method.

```html
<form method="POST" action="process.php">
  <input type="text" name="username">
  <input type="password" name="password">
  <button type="submit">Login</button>
</form>
```

```php
<?php
// In process.php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $username = $_POST['username'];
  $password = $_POST['password'];
  
  echo "Username: " . htmlspecialchars($username);
}
?>
```

**Common uses:**
* Login forms
* Registration
* Contact forms
* Any sensitive data

**Why use POST instead of GET?**
* Data not visible in URL
* Can send more data
* More secure for passwords
* Better for database modifications

## $_REQUEST - Combined Data

Contains data from both $_GET and $_POST (and $_COOKIE).

```php
<?php
// Works for both GET and POST
$username = $_REQUEST['username'];
echo "Username: " . htmlspecialchars($username);
?>
```

**Note:** It's better to use $_GET or $_POST specifically to know where data comes from.

## $_SERVER - Server Information

Contains information about the server, request, and environment.

**Common $_SERVER variables:**

```php
<?php
// Current script name
echo $_SERVER['PHP_SELF'] . "<br>";

// Server name
echo $_SERVER['SERVER_NAME'] . "<br>";

// Request method (GET, POST, etc.)
echo $_SERVER['REQUEST_METHOD'] . "<br>";

// User's IP address
echo $_SERVER['REMOTE_ADDR'] . "<br>";

// Current page URL
echo $_SERVER['REQUEST_URI'] . "<br>";

// HTTP host
echo $_SERVER['HTTP_HOST'] . "<br>";

// User agent (browser info)
echo $_SERVER['HTTP_USER_AGENT'] . "<br>";

// Document root directory
echo $_SERVER['DOCUMENT_ROOT'] . "<br>";

// Current script filename
echo $_SERVER['SCRIPT_FILENAME'] . "<br>";

// Server software
echo $_SERVER['SERVER_SOFTWARE'] . "<br>";
?>
```

**Practical examples:**

**Redirect to homepage:**
```php
<?php
header("Location: http://" . $_SERVER['HTTP_HOST'] . "/index.php");
exit();
?>
```

**Check request method:**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  // Handle form submission
} else {
  // Show the form
}
?>
```

**Get current page URL:**
```php
<?php
$currentURL = "http://" . $_SERVER['HTTP_HOST'] . $_SERVER['REQUEST_URI'];
echo "Current URL: " . $currentURL;
?>
```

## $_SESSION - Session Data

Sessions store user data across multiple pages. Perfect for login systems!

**Start a session:**
```php
<?php
session_start(); // Always call this first!
?>
```

**Store session data:**
```php
<?php
session_start();

// Store data
$_SESSION['username'] = "Alice";
$_SESSION['user_id'] = 123;
$_SESSION['role'] = "admin";

echo "Session data saved!";
?>
```

**Read session data:**
```php
<?php
session_start();

// Check if logged in
if (isset($_SESSION['username'])) {
  echo "Welcome, " . $_SESSION['username'];
} else {
  echo "Please log in";
}
?>
```

**Delete specific session variable:**
```php
<?php
session_start();
unset($_SESSION['username']);
?>
```

**Destroy entire session (logout):**
```php
<?php
session_start();
session_destroy();
echo "Logged out!";
?>
```

**Common uses:**
* User login status
* Shopping carts
* User preferences
* Multi-step forms

## $_COOKIE - Cookie Data

Cookies store small data on user's browser. They persist even after closing browser.

**Create a cookie:**
```php
<?php
// setcookie(name, value, expiration, path, domain, secure, httponly)
setcookie("username", "Alice", time() + 86400, "/"); // 86400 = 1 day

echo "Cookie set!";
?>
```

**Read a cookie:**
```php
<?php
if (isset($_COOKIE['username'])) {
  echo "Welcome back, " . $_COOKIE['username'];
} else {
  echo "First time visitor";
}
?>
```

**Delete a cookie:**
```php
<?php
// Set expiration to past
setcookie("username", "", time() - 3600, "/");
echo "Cookie deleted!";
?>
```

**Cookie parameters explained:**
* `name` - cookie name
* `value` - cookie value
* `expiration` - when it expires (timestamp)
* `path` - where cookie is available (/ = entire site)
* `domain` - domain where cookie is available
* `secure` - only send over HTTPS
* `httponly` - not accessible via JavaScript

**Sessions vs Cookies:**
* Sessions - stored on server, more secure
* Cookies - stored on user's browser, can be viewed/modified

## $_FILES - File Uploads

Contains information about uploaded files.

**HTML form:**
```html
<form method="POST" enctype="multipart/form-data">
  <input type="file" name="myfile">
  <button type="submit">Upload</button>
</form>
```

**PHP handling:**
```php
<?php
if (isset($_FILES['myfile'])) {
  $file = $_FILES['myfile'];
  
  echo "Name: " . $file['name'] . "<br>";
  echo "Type: " . $file['type'] . "<br>";
  echo "Size: " . $file['size'] . " bytes<br>";
  echo "Temp location: " . $file['tmp_name'] . "<br>";
  echo "Error: " . $file['error'] . "<br>";
  
  // Move uploaded file
  move_uploaded_file($file['tmp_name'], "uploads/" . $file['name']);
}
?>
```

**$_FILES array structure:**
* `name` - original filename
* `type` - MIME type
* `size` - file size in bytes
* `tmp_name` - temporary location on server
* `error` - error code (0 = success)

## $_ENV - Environment Variables

Contains environment variables from the server.

```php
<?php
// Get environment variable
$path = $_ENV['PATH'];
echo $path;

// Alternative using getenv()
$user = getenv('USER');
echo $user;
?>
```

**Note:** Not all servers expose environment variables. It depends on server configuration.

## $GLOBALS - All Global Variables

Contains all global variables in the script.

```php
<?php
$x = 10;
$y = 20;

function add() {
  $GLOBALS['z'] = $GLOBALS['x'] + $GLOBALS['y'];
}

add();
echo $z; // 30
?>
```

**Access global without global keyword:**
```php
<?php
$message = "Hello";

function sayHello() {
  echo $GLOBALS['message']; // Access global directly
}

sayHello(); // Hello
?>
```

## Security Best Practices

**Always sanitize superglobal data!**

**1. Use htmlspecialchars() for output:**
```php
<?php
$name = htmlspecialchars($_GET['name'], ENT_QUOTES, 'UTF-8');
echo "Hello, " . $name;
?>
```

**2. Validate and filter:**
```php
<?php
$email = filter_var($_POST['email'], FILTER_VALIDATE_EMAIL);
if ($email === false) {
  echo "Invalid email";
}
?>
```

**3. Check if data exists:**
```php
<?php
if (isset($_POST['username']) && !empty($_POST['username'])) {
  $username = trim($_POST['username']);
  // Process username
}
?>
```

**4. Use prepared statements for databases:**
```php
<?php
// NEVER do this:
$sql = "SELECT * FROM users WHERE username = '" . $_POST['username'] . "'";

// ALWAYS use prepared statements:
$stmt = $pdo->prepare("SELECT * FROM users WHERE username = ?");
$stmt->execute([$_POST['username']]);
?>
```

## Quick Recap

**Most used superglobals:**
* `$_GET` - for URL data
* `$_POST` - for form data
* `$_SERVER` - for server/request info
* `$_SESSION` - for user sessions
* `$_COOKIE` - for cookies

**Always remember:**
* Check if data exists with `isset()`
* Sanitize all user input
* Use `htmlspecialchars()` for output
* Never trust user data
* Sessions need `session_start()` first
* Cookies must be set before any output

**Common patterns:**
```php
// Check and sanitize GET data
if (isset($_GET['id'])) {
  $id = filter_var($_GET['id'], FILTER_VALIDATE_INT);
}

// Check POST submission
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  // process form
}

// Check session login
session_start();
if (isset($_SESSION['user_id'])) {
  // user is logged in
}
```

Superglobals give you access to important data, but always handle them securely!

# Functions in JavaScript

Functions are blocks of code that perform specific tasks. You've already learned the basics. Now let's dive deeper into advanced function concepts that make your code more powerful and flexible.

## Function Types Recap

**Function Declaration:**
```js
function greet(name) {
  return "Hello, " + name;
}
```

**Function Expression:**
```js
let greet = function(name) {
  return "Hello, " + name;
};
```

**Arrow Function:**
```js
let greet = (name) => "Hello, " + name;
```

## Higher-Order Functions

Functions that take other functions as arguments or return functions are called "higher-order functions."

**Function as argument:**
```js
function calculate(a, b, operation) {
  return operation(a, b);
}

let add = function(x, y) {
  return x + y;
};

let result = calculate(5, 3, add);
alert(result); // 8
```

**Function as return value:**
```js
function createMultiplier(multiplier) {
  return function(number) {
    return number * multiplier;
  };
}

let double = createMultiplier(2);
alert(double(5)); // 10

let triple = createMultiplier(3);
alert(triple(5)); // 15
```

## Closures

A closure is when a function remembers variables from its outer scope even after the outer function has finished.

```js
function outerFunction(x) {
  // This variable is in the outer scope
  let outerVariable = x;
  
  function innerFunction(y) {
    // Inner function can access outerVariable
    return outerVariable + y;
  }
  
  return innerFunction;
}

let addFive = outerFunction(5);
alert(addFive(3)); // 8 (5 + 3)
```

**Practical example:**
```js
function createCounter() {
  let count = 0;
  
  return function() {
    count++;
    return count;
  };
}

let counter = createCounter();
alert(counter()); // 1
alert(counter()); // 2
alert(counter()); // 3
```

The `count` variable is "closed over" by the inner function, so it persists between calls.

## Default Parameters

You can set default values for parameters:

```js
function greet(name = "Guest") {
  return "Hello, " + name;
}

alert(greet("Alice")); // Hello, Alice
alert(greet());        // Hello, Guest
```

**Multiple defaults:**
```js
function createUser(name, age = 18, isActive = true) {
  return {
    name: name,
    age: age,
    isActive: isActive
  };
}

let user1 = createUser("Alice");           // age: 18, isActive: true
let user2 = createUser("Bob", 25);         // isActive: true
let user3 = createUser("Charlie", 30, false); // all specified
```

## Rest Parameters

Use `...` to collect multiple arguments into an array:

```js
function sum(...numbers) {
  let total = 0;
  for (let num of numbers) {
    total += num;
  }
  return total;
}

alert(sum(1, 2, 3));        // 6
alert(sum(1, 2, 3, 4, 5));  // 15
```

**Rest must be last:**
```js
function introduce(firstName, lastName, ...hobbies) {
  alert(`${firstName} ${lastName} likes: ${hobbies.join(", ")}`);
}

introduce("Alice", "Smith", "reading", "coding", "music");
// Alice Smith likes: reading, coding, music
```

## Spread Operator

The spread operator `...` expands an array into individual values:

```js
let numbers = [1, 2, 3];

// Spread into function arguments
alert(Math.max(...numbers)); // 3 (same as Math.max(1, 2, 3))

// Spread into array
let moreNumbers = [...numbers, 4, 5];
alert(moreNumbers); // 1, 2, 3, 4, 5
```

## Immediately Invoked Function Expressions (IIFE)

An IIFE runs immediately when defined:

```js
(function() {
  alert("This runs immediately!");
})();
```

**Why use IIFE?**
* Creates a private scope
* Avoids polluting global namespace
* Runs code immediately

```js
(function() {
  let privateVariable = "secret";
  // This variable is not accessible outside
})();

// privateVariable is not accessible here
```

## Recursive Functions

A function that calls itself is recursive:

```js
function factorial(n) {
  if (n === 0 || n === 1) {
    return 1;
  }
  return n * factorial(n - 1);
}

alert(factorial(5)); // 120 (5 × 4 × 3 × 2 × 1)
```

**Another example:**
```js
function countdown(n) {
  if (n <= 0) {
    alert("Blast off!");
    return;
  }
  alert(n);
  countdown(n - 1);
}

countdown(5); // 5, 4, 3, 2, 1, Blast off!
```

**Important:** Always have a base case (stopping condition) or you'll get infinite recursion!

## Callback Functions

A callback is a function passed to another function to be called later:

```js
function processData(data, callback) {
  // Do some processing
  let result = data * 2;
  
  // Call the callback with the result
  callback(result);
}

processData(5, function(result) {
  alert("Result: " + result); // Result: 10
});
```

**Common with array methods:**
```js
let numbers = [1, 2, 3, 4, 5];

numbers.forEach(function(num) {
  alert(num * 2); // callback function
});
```

## Function Methods: call, apply, bind

**call() - calls function with specific `this`:**
```js
let person = {
  name: "Alice",
  greet: function() {
    alert("Hello, " + this.name);
  }
};

let anotherPerson = { name: "Bob" };

person.greet.call(anotherPerson); // Hello, Bob
```

**apply() - like call, but takes array of arguments:**
```js
function introduce(greeting, punctuation) {
  alert(greeting + ", I'm " + this.name + punctuation);
}

let person = { name: "Alice" };
introduce.apply(person, ["Hi", "!"]); // Hi, I'm Alice!
```

**bind() - creates new function with bound `this`:**
```js
let person = {
  name: "Alice",
  greet: function() {
    alert("Hello, " + this.name);
  }
};

let boundGreet = person.greet.bind(person);
boundGreet(); // Hello, Alice
```

## Quick Recap

**Advanced function concepts:**
* Higher-order functions - functions that work with other functions
* Closures - functions that remember outer variables
* Default parameters - set default values
* Rest parameters - collect multiple arguments
* Spread operator - expand arrays/objects
* IIFE - immediately executed functions
* Recursion - functions that call themselves
* Callbacks - functions passed as arguments
* call/apply/bind - control `this` context

**When to use what:**
* Default parameters - when some arguments are optional
* Rest parameters - when you don't know how many arguments
* Closures - when you need private variables
* Recursion - for problems that break into smaller versions
* Callbacks - for async operations and array methods

Functions are powerful tools. Master these concepts to write more flexible and reusable code!

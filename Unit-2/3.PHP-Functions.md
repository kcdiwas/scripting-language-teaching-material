# PHP Functions

Functions in PHP are blocks of reusable code that perform specific tasks. They help organize your code and make it easier to maintain.

## Creating Basic Functions

**Simple function:**
```php
<?php
function greet() {
  echo "Hello, World!";
}

greet(); // Call the function
?>
```

**Function with parameters:**
```php
<?php
function greet($name) {
  echo "Hello, " . $name . "!";
}

greet("Alice"); // Hello, Alice!
greet("Bob");   // Hello, Bob!
?>
```

**Function with multiple parameters:**
```php
<?php
function addNumbers($a, $b) {
  echo $a + $b;
}

addNumbers(5, 3); // 8
?>
```

## Return Values

Functions can return values instead of just printing:

```php
<?php
function add($a, $b) {
  return $a + $b;
}

$result = add(10, 5);
echo $result; // 15

// Use directly in expressions
echo "Sum: " . add(20, 10); // Sum: 30
?>
```

**Return early:**
```php
<?php
function isEven($number) {
  if ($number % 2 == 0) {
    return true;
  }
  return false;
}

if (isEven(4)) {
  echo "Number is even";
}
?>
```

## Default Parameters

Set default values for parameters:

```php
<?php
function greet($name = "Guest") {
  echo "Hello, " . $name;
}

greet("Alice"); // Hello, Alice
greet();        // Hello, Guest
?>
```

**Multiple defaults:**
```php
<?php
function createUser($name, $age = 18, $active = true) {
  echo "Name: $name, Age: $age, Active: " . ($active ? "Yes" : "No");
}

createUser("Alice");           // Age: 18, Active: Yes
createUser("Bob", 25);         // Age: 25, Active: Yes
createUser("Charlie", 30, false); // Age: 30, Active: No
?>
```

## Variable Number of Arguments

**Using func_get_args():**
```php
<?php
function sum() {
  $numbers = func_get_args();
  $total = 0;
  
  foreach ($numbers as $num) {
    $total += $num;
  }
  
  return $total;
}

echo sum(1, 2, 3);        // 6
echo sum(1, 2, 3, 4, 5);  // 15
?>
```

**Using spread operator (PHP 5.6+):**
```php
<?php
function sum(...$numbers) {
  $total = 0;
  foreach ($numbers as $num) {
    $total += $num;
  }
  return $total;
}

echo sum(1, 2, 3, 4); // 10
?>
```

## Type Declarations

Specify parameter and return types (PHP 7+):

```php
<?php
function add(int $a, int $b): int {
  return $a + $b;
}

echo add(5, 3); // 8
// add("5", "3"); // Type error in strict mode
?>
```

**Common types:**
* `int` - integer
* `float` - floating point number
* `string` - text
* `bool` - boolean (true/false)
* `array` - array
* `object` - object

```php
<?php
function greet(string $name): string {
  return "Hello, " . $name;
}

function isAdult(int $age): bool {
  return $age >= 18;
}

function getScores(): array {
  return [85, 92, 78];
}
?>
```

## Variable Functions

Store function names in variables:

```php
<?php
function sayHello() {
  echo "Hello!";
}

$func = "sayHello";
$func(); // calls sayHello()
?>
```

## Anonymous Functions (Closures)

Functions without names:

```php
<?php
$greet = function($name) {
  echo "Hello, " . $name;
};

$greet("Alice"); // Hello, Alice
?>
```

**Use with array functions:**
```php
<?php
$numbers = [1, 2, 3, 4, 5];

$doubled = array_map(function($n) {
  return $n * 2;
}, $numbers);

print_r($doubled); // [2, 4, 6, 8, 10]
?>
```

**Closures with use:**
```php
<?php
$message = "Hello";

$greet = function($name) use ($message) {
  echo $message . ", " . $name;
};

$greet("Alice"); // Hello, Alice
?>
```

## Arrow Functions (PHP 7.4+)

Short syntax for simple functions:

```php
<?php
$multiply = fn($a, $b) => $a * $b;

echo $multiply(5, 3); // 15
?>
```

**With array functions:**
```php
<?php
$numbers = [1, 2, 3, 4, 5];
$doubled = array_map(fn($n) => $n * 2, $numbers);

print_r($doubled); // [2, 4, 6, 8, 10]
?>
```

## Recursive Functions

Functions that call themselves:

```php
<?php
function factorial($n) {
  if ($n <= 1) {
    return 1;
  }
  return $n * factorial($n - 1);
}

echo factorial(5); // 120 (5 × 4 × 3 × 2 × 1)
?>
```

**Countdown example:**
```php
<?php
function countdown($n) {
  if ($n <= 0) {
    echo "Blast off!<br>";
    return;
  }
  echo $n . "<br>";
  countdown($n - 1);
}

countdown(5); // 5, 4, 3, 2, 1, Blast off!
?>
```

## Variable Scope

**Local scope:**
```php
<?php
function test() {
  $localVar = "I'm local";
  echo $localVar; // works
}

test();
// echo $localVar; // Error: variable doesn't exist here
?>
```

**Global scope:**
```php
<?php
$globalVar = "I'm global";

function test() {
  global $globalVar; // Must declare global to use
  echo $globalVar;
}

test(); // I'm global
?>
```

**GLOBALS array:**
```php
<?php
$x = 10;

function test() {
  echo $GLOBALS['x']; // Access global without global keyword
}

test(); // 10
?>
```

**Static variables:**
```php
<?php
function counter() {
  static $count = 0; // Retains value between calls
  $count++;
  echo $count . "<br>";
}

counter(); // 1
counter(); // 2
counter(); // 3
?>
```

## Built-in Useful Functions

**String functions:**
```php
<?php
echo strlen("Hello");        // 5 (length)
echo strtoupper("hello");    // HELLO
echo strtolower("HELLO");    // hello
echo substr("Hello", 0, 3);  // Hel
echo str_replace("o", "0", "Hello"); // Hell0
?>
```

**Array functions:**
```php
<?php
$arr = [1, 2, 3, 4, 5];

echo count($arr);           // 5
echo max($arr);             // 5
echo min($arr);             // 1
echo array_sum($arr);       // 15
print_r(array_reverse($arr)); // [5, 4, 3, 2, 1]
?>
```

**Math functions:**
```php
<?php
echo abs(-5);      // 5
echo round(3.7);   // 4
echo ceil(3.2);    // 4 (round up)
echo floor(3.8);   // 3 (round down)
echo rand(1, 10);  // random number 1-10
?>
```

## Pass by Reference

Modify the original variable:

```php
<?php
function addTen(&$number) {
  $number += 10;
}

$value = 5;
addTen($value);
echo $value; // 15 (original changed!)
?>
```

## Quick Recap

**Function basics:**
```php
function functionName($param1, $param2) {
  // code
  return $result;
}
```

**Key concepts:**
* Default parameters: `function greet($name = "Guest")`
* Variable arguments: `function sum(...$numbers)`
* Type declarations: `function add(int $a, int $b): int`
* Anonymous functions: `$func = function() { };`
* Arrow functions: `$func = fn($x) => $x * 2;`
* Recursive functions: function calls itself
* Pass by reference: `function modify(&$var)`
* Scope: local, global, static

**Variable scope:**
* Local variables only exist inside functions
* Use `global` keyword or `$GLOBALS` for global variables
* Static variables retain values between calls

**Best practices:**
* Use descriptive function names
* Keep functions small and focused
* Use type declarations when possible
* Return values instead of echoing when possible
* Document complex functions with comments

Functions make your PHP code organized, reusable, and easier to test!

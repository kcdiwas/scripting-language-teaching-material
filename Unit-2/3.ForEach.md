# ForEach Loops

The `forEach` method is a simple way to loop through arrays. It runs a function once for each item in the array. It's cleaner and easier to read than traditional `for` loops.

## Basic Syntax

```js
array.forEach(function(item) {
  // do something with item
});
```

The function you pass to `forEach` gets called once for each element in the array.

## Simple Example

```js
let fruits = ["Apple", "Orange", "Banana"];

fruits.forEach(function(fruit) {
  alert(fruit);
});
```

This shows each fruit one by one: Apple, then Orange, then Banana.

## Getting the Index

You can also get the index (position) of each item:

```js
let fruits = ["Apple", "Orange", "Banana"];

fruits.forEach(function(fruit, index) {
  alert(`${index}: ${fruit}`);
});
```

This shows:
* 0: Apple
* 1: Orange
* 2: Banana

## Getting the Array

The function can also receive the entire array as a third parameter:

```js
let numbers = [10, 20, 30];

numbers.forEach(function(number, index, array) {
  alert(`Item ${index} of ${array.length} is ${number}`);
});
```

This shows:
* Item 0 of 3 is 10
* Item 1 of 3 is 20
* Item 2 of 3 is 30

## Using Arrow Functions

You can make it shorter with arrow functions:

```js
let fruits = ["Apple", "Orange", "Banana"];

// Traditional function
fruits.forEach(function(fruit) {
  alert(fruit);
});

// Arrow function (shorter!)
fruits.forEach(fruit => alert(fruit));
```

## Common Use Cases

**Calculate sum:**
```js
let numbers = [5, 10, 15, 20];
let sum = 0;

numbers.forEach(function(num) {
  sum += num;
});

alert(sum); // 50
```

**Update elements:**
```js
let prices = [10, 20, 30];

prices.forEach(function(price, index, array) {
  array[index] = price * 1.1; // add 10% tax
});

alert(prices); // 11, 22, 33
```

**Work with objects:**
```js
let students = [
  {name: "Alice", grade: 85},
  {name: "Bob", grade: 92},
  {name: "Charlie", grade: 78}
];

students.forEach(function(student) {
  alert(`${student.name} got ${student.grade}`);
});
```

## Important Notes

**forEach doesn't return anything:**
```js
let numbers = [1, 2, 3];
let result = numbers.forEach(function(num) {
  return num * 2; // this return is ignored!
});

alert(result); // undefined
```

If you need to create a new array, use `map()` instead.

**You can't break out of forEach:**
```js
let numbers = [1, 2, 3, 4, 5];

numbers.forEach(function(num) {
  if (num === 3) {
    break; // ERROR! Can't use break in forEach
  }
  alert(num);
});
```

If you need to stop early, use a regular `for` loop or `for...of`.

**forEach skips empty slots:**
```js
let arr = [1, , 3]; // empty slot at index 1

arr.forEach(function(item) {
  alert(item); // shows 1, then 3 (skips the empty slot)
});
```

## forEach vs Other Loops

**forEach vs for loop:**
```js
let arr = [1, 2, 3];

// Traditional for loop
for (let i = 0; i < arr.length; i++) {
  alert(arr[i]);
}

// forEach (cleaner)
arr.forEach(function(item) {
  alert(item);
});
```

**forEach vs for...of:**
```js
let arr = [1, 2, 3];

// for...of
for (let item of arr) {
  alert(item);
}

// forEach
arr.forEach(function(item) {
  alert(item);
});
```

Both work similarly, but `forEach` is more functional and `for...of` can use `break` and `continue`.

## Quick Recap

**Basic usage:**
```js
array.forEach(function(item) {
  // code here
});
```

**With index:**
```js
array.forEach(function(item, index) {
  // code here
});
```

**With arrow functions:**
```js
array.forEach(item => {
  // code here
});
```

**Key points:**
* Runs a function for each array element
* Can access item, index, and the whole array
* Doesn't return a new array (use `map` for that)
* Can't use `break` or `continue`
* Cleaner than traditional `for` loops
* Great for side effects (alerts, updates, etc.)

Use `forEach` when you want to do something with each item but don't need a new array!

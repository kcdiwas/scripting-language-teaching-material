# PHP Form Handling Practice Problems

## Problem 1: Simple Contact Form

Create a contact form with the following requirements:

**HTML Form (contact.php):**
* Name field (text input)
* Email field (email input)
* Message field (textarea)
* Submit button

**PHP Requirements:**
* Use POST method
* Display all submitted data after form submission
* Show "Form submitted successfully!" message
* Keep the form on the same page (use `$_SERVER['PHP_SELF']`)

**Expected output after submission:**
```
Form submitted successfully!

Name: John Doe
Email: john@example.com
Message: Hello, this is a test message.
```

**Hint:** Check if form was submitted using `$_SERVER["REQUEST_METHOD"] == "POST"`

## Problem 2: Registration Form with Validation

Create a registration form with validation:

**Form fields:**
* Username (minimum 3 characters, maximum 20 characters)
* Email (must be valid email format)
* Password (minimum 6 characters)
* Confirm Password (must match password)
* Age (must be a number, minimum 18)

**Requirements:**
* Validate all fields on server-side
* Show error messages if validation fails
* Show success message if all validations pass
* Keep filled values in form fields after submission (except passwords)
* Use `htmlspecialchars()` to prevent XSS attacks

**Expected output with errors:**
```
Username is required
Email format is invalid
Password must be at least 6 characters
Passwords do not match
Must be 18 or older
```

**Expected output on success:**
```
Registration successful!
Welcome, username123
```

**Hint:** Create an `$errors` array to collect all validation errors.

## Problem 3: Survey Form with Different Input Types

Create a survey form that includes:

**Form fields:**
* Name (text input)
* Gender (radio buttons: Male, Female, Other)
* Hobbies (checkboxes: Reading, Sports, Music, Gaming, Coding)
* Country (select dropdown: USA, UK, India, Australia, Canada)
* Comments (textarea)

**Requirements:**
* Use POST method
* Handle radio buttons (show selected gender)
* Handle multiple checkboxes (show all selected hobbies)
* Handle select dropdown (show selected country)
* Display all submitted data in a formatted way

**Expected output:**
```
Survey Results:
--------------
Name: Alice Smith
Gender: Female
Hobbies: Reading, Music, Coding
Country: USA
Comments: I enjoy participating in surveys.
```

**Hint:** Use `isset()` to check if checkboxes were selected. Use `[]` in checkbox names to get an array.

## Problem 4: Login Form with Session

Create a simple login system:

**Files needed:**
* login.php (login form)
* dashboard.php (protected page)
* logout.php (logout script)

**Login form requirements:**
* Username field
* Password field
* Submit button

**Hardcoded credentials for testing:**
* Username: "admin"
* Password: "password123"

**Requirements:**
* Check credentials on submission
* If correct: create session, redirect to dashboard
* If incorrect: show error message
* Dashboard should show "Welcome, admin!" and logout link
* Dashboard should check if user is logged in (redirect to login if not)
* Logout should destroy session and redirect to login

**Expected flow:**
```
1. User enters correct credentials
2. Redirected to dashboard.php
3. Dashboard shows: "Welcome, admin! [Logout]"
4. Click logout
5. Redirected back to login.php
```

**Hint:** Use `session_start()`, `$_SESSION`, `header("Location: ...")`, and `session_destroy()`.

## Problem 5: Multi-Step Form (Advanced)

Create a 3-step registration form:

**Step 1 - Personal Info:**
* First Name
* Last Name
* Email

**Step 2 - Account Details:**
* Username
* Password
* Confirm Password

**Step 3 - Preferences:**
* Country (dropdown)
* Newsletter (checkbox: Yes/No)

**Requirements:**
* Use sessions to store data between steps
* Each step validates its own fields
* Show "Previous" and "Next" buttons (except first and last)
* Last step shows all collected data and "Submit" button
* After final submission, display all information and clear session

**Expected flow:**
```
Step 1: Enter personal info → Click Next
Step 2: Enter account details → Click Next
Step 3: Select preferences → Click Submit

Final Page:
Registration Complete!
Name: John Doe
Email: john@example.com
Username: johndoe
Country: USA
Newsletter: Yes
```

**Hint:** Use a hidden input to track current step. Store data in `$_SESSION['step1']`, `$_SESSION['step2']`, etc.

## Bonus Problem: File Upload Form

Create a file upload form:

**Form requirements:**
* File input (accept only images: jpg, png, gif)
* Alt text input (for image description)
* Submit button

**Validation requirements:**
* Check if file was uploaded
* Validate file type (only jpg, png, gif allowed)
* Validate file size (maximum 2MB)
* Generate unique filename to prevent overwriting
* Save file to "uploads/" directory
* Display uploaded image after successful upload

**Expected output on success:**
```
File uploaded successfully!
Filename: image_12345.jpg
Size: 1.5 MB
Alt text: Beautiful sunset

[Display the uploaded image]
```

**Expected output on error:**
```
Error: Only JPG, PNG, and GIF files are allowed
OR
Error: File size must be less than 2MB
```

**Hint:** Use `$_FILES`, `move_uploaded_file()`, `pathinfo()`, and `time()` for unique names.

## Challenge Problem: Dynamic Form with Add/Remove Fields

Create a form where users can add/remove multiple phone numbers:

**Requirements:**
* Initial form shows one phone input
* "Add Phone" button (using JavaScript) adds more inputs
* "Remove" button next to each phone field (except first one)
* Submit button
* PHP processes all phone numbers
* Display all submitted phone numbers

**Expected output:**
```
Submitted Phone Numbers:
1. +1-555-0101
2. +1-555-0102
3. +1-555-0103
```

**Hint:** Use array names like `phone[]` in HTML. PHP will receive them as an array in `$_POST['phone']`. Use JavaScript for add/remove functionality.

## Testing Checklist

For each problem, test:
* ✓ Form displays correctly
* ✓ Required fields show errors when empty
* ✓ Validation works for each field
* ✓ Success message appears when valid
* ✓ XSS prevention (test with `<script>alert('XSS')</script>`)
* ✓ Data persists in form fields after validation errors
* ✓ Sensitive data (passwords) not shown in form after submission

## Common Functions You'll Need

```php
// Check if form submitted
if ($_SERVER["REQUEST_METHOD"] == "POST") { }

// Check if field exists and not empty
if (isset($_POST['field']) && !empty($_POST['field'])) { }

// Sanitize output
htmlspecialchars($data, ENT_QUOTES, 'UTF-8')

// Validate email
filter_var($email, FILTER_VALIDATE_EMAIL)

// Trim whitespace
trim($data)

// String length
strlen($data)

// Start session
session_start()

// Redirect
header("Location: page.php");
exit();
```

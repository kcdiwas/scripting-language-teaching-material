## 1\. Introduction to MySQL

**MySQL** is the world's most popular open-source relational database management system (RDBMS).

  * **Relational:** Data is stored in tables (rows and columns).
  * **SQL:** It uses **S**tructured **Q**uery **L**anguage to manage data.
  * **Client-Server:** The database sits on a server; PHP (the client) asks it for data.

-----

## 2\. Connecting & Closing (MySQLi Procedural)

Before you can do anything, you must open a "line" to the database.

### **Connecting**

```php
$conn = mysqli_connect("localhost", "username", "password", "database_name");

// Check connection
if (!$conn) {
    die("Connection failed: " . mysqli_connect_error());
}
```

### **Closing**

Always close the connection at the end of your script to save server memory.

```php
mysqli_close($conn);
```

-----

## 3\. MySQL Data Types

When creating a table, you must define what kind of data each column holds.

| Type | Description | Example |
| :--- | :--- | :--- |
| **INT** | Whole numbers. | `1`, `100`, `-5` |
| **FLOAT** / **DECIMAL** | Numbers with decimals (money, grades). | `10.5`, `99.99` |
| **VARCHAR(255)** | Variable-length strings (letters/numbers). | `"John Doe"`, `"user@email.com"` |
| **TEXT** | Long text strings. | Blog posts, comments. |
| **DATE** | Format: YYYY-MM-DD. | `2023-12-25` |
| **DATETIME** | Date + Time. | `2023-12-25 14:30:00` |

## 4\. Basic Operations (CRUD)

### **INSERT (Create Data)**

Adds a new row to a table.
**Syntax:** `INSERT INTO table (col1, col2) VALUES (val1, val2)`

```php
$sql = "INSERT INTO students (name, email, age) 
        VALUES ('Alice Smith', 'alice@example.com', 20)";

if (mysqli_query($conn, $sql)) {
    echo "New record created!";
}
```

### **SELECT (Read Data)**

Retrieves data from the database.
**Syntax:** `SELECT col1, col2 FROM table`

```php
$sql = "SELECT id, name FROM students";
$result = mysqli_query($conn, $sql);

while($row = mysqli_fetch_assoc($result)) {
    echo $row["name"] . "<br>";
}
```

### **UPDATE (Modify Data)**

Changes existing data. **WARNING:** Always use a `WHERE` clause, or you will update *every* row\!
**Syntax:** `UPDATE table SET col=val WHERE condition`

```php
$sql = "UPDATE students SET age = 21 WHERE name = 'Alice Smith'";
mysqli_query($conn, $sql);
```

### **DELETE (Remove Data)**

Removes rows. **WARNING:** Always use a `WHERE` clause, or you will wipe the table\!
**Syntax:** `DELETE FROM table WHERE condition`

```php
$sql = "DELETE FROM students WHERE id = 5";
mysqli_query($conn, $sql);
```

## 5\. Filtering and Sorting

### **WHERE Clause**

Used to filter records.

```sql
SELECT * FROM students WHERE age > 18;
SELECT * FROM students WHERE name = 'John';
```

### **ORDER BY Clause**

Sorts the result set. Default is **ASC** (Ascending). Use **DESC** for Descending.

```sql
SELECT * FROM students ORDER BY age DESC; -- Oldest first
SELECT * FROM students ORDER BY name ASC; -- A-Z
```

## 6\. Grouping and Aggregates

### **Aggregate Functions**

Math functions that perform calculations on a set of values.

| Function | Description | Example SQL |
| :--- | :--- | :--- |
| `COUNT()` | Counts number of rows. | `SELECT COUNT(*) FROM students;` |
| `SUM()` | Adds up values. | `SELECT SUM(fees) FROM payments;` |
| `AVG()` | Calculates average. | `SELECT AVG(marks) FROM results;` |
| `MIN()` | Finds smallest value. | `SELECT MIN(age) FROM students;` |
| `MAX()` | Finds largest value. | `SELECT MAX(age) FROM students;` |

### **GROUP BY Clause**

Groups rows that have the same values into summary rows. Usually used with aggregate functions.

**Example:** Count how many students are in *each* class.

```sql
SELECT class_name, COUNT(*) 
FROM students 
GROUP BY class_name;
```

*Result:*

  * Science: 15
  * Math: 20

## 7\. Advanced Concepts

### **Subqueries (Nested Queries)**

A query inside another query.

**Example:** Find students who scored *above the average*.

1.  Inner Query: Calculate the average.
2.  Outer Query: Select students with marks higher than that number.

<!-- end list -->

```sql
SELECT name, marks 
FROM students 
WHERE marks > (SELECT AVG(marks) FROM students);
```

### **JOINS**

Used to combine rows from two or more tables, based on a related column between them.

**Scenario:**

  * **Table 1 (Users):** `user_id`, `name`
  * **Table 2 (Orders):** `order_id`, `user_id`, `product`

**1. INNER JOIN (Most Common)**
Returns records that have matching values in **both** tables.

```sql
SELECT Users.name, Orders.product
FROM Users
INNER JOIN Orders ON Users.user_id = Orders.user_id;
```

*Result:* Only users who have placed an order.

**2. LEFT JOIN**
Returns **all** records from the left table (Users), and the matched records from the right table (Orders).

```sql
SELECT Users.name, Orders.product
FROM Users
LEFT JOIN Orders ON Users.user_id = Orders.user_id;
```

*Result:* All users are listed. If a user hasn't ordered anything, the product column will say `NULL`.

**3. RIGHT JOIN**
Returns **all** records from the right table (Orders), and the matched records from the left table (Users).

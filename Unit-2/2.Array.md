# Arrays in PHP

Arrays are used to store multiple values in a single variable. Unlike JavaScript arrays, PHP arrays can be **indexed arrays** (with numeric keys) or **associative arrays** (with named keys). PHP arrays are very flexible and powerful.

## What are Arrays?

An array is a special variable that can hold multiple values at once. Think of it like a container with multiple compartments, each holding a value.

**Why use arrays?**
- Store lists of items (names, numbers, etc.)
- Group related data together
- Easily loop through multiple values
- Organize data efficiently

## Types of Arrays in PHP

PHP has three types of arrays:

1. **Indexed Arrays** - Numeric keys (0, 1, 2, ...)
2. **Associative Arrays** - Named keys ("name", "age", etc.)
3. **Multidimensional Arrays** - Arrays within arrays

## Creating Arrays

### Method 1: Using array() Function

```php
<?php
    // Indexed array
    $fruits = array("Apple", "Orange", "Banana");
    
    // Associative array
    $person = array("name" => "John", "age" => 25, "city" => "New York");
?>
```

### Method 2: Using Short Array Syntax [] (PHP 5.4+)

```php
<?php
    // Indexed array (modern way)
    $fruits = ["Apple", "Orange", "Banana"];
    
    // Associative array
    $person = ["name" => "John", "age" => 25, "city" => "New York"];
?>
```

```smart header="Which syntax to use?"
Both `array()` and `[]` work the same way. The `[]` syntax is shorter and more modern (similar to JavaScript). Use whichever you prefer, but `[]` is more commonly used in modern PHP code.
```

## Indexed Arrays

Indexed arrays use numeric keys starting from 0.

### Creating Indexed Arrays

```php
<?php
    // Create indexed array
    $fruits = ["Apple", "Orange", "Banana"];
    
    // Access elements by index
    echo $fruits[0];  // Apple
    echo $fruits[1];  // Orange
    echo $fruits[2];  // Banana
    
    // Get array length
    echo count($fruits);  // 3
?>
```

### Adding Elements

```php
<?php
    $fruits = ["Apple", "Orange"];
    
    // Add to end
    $fruits[] = "Banana";  // Now: ["Apple", "Orange", "Banana"]
    
    // Add at specific index
    $fruits[3] = "Grape";  // Now: ["Apple", "Orange", "Banana", "Grape"]
    
    // Add multiple
    array_push($fruits, "Mango", "Kiwi");
?>
```

### Modifying Elements

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    
    // Change an element
    $fruits[1] = "Grape";  // Now: ["Apple", "Grape", "Banana"]
    
    echo $fruits[1];  // Grape
?>
```

## Associative Arrays

Associative arrays use named keys instead of numeric indices.

### Creating Associative Arrays

```php
<?php
    // Create associative array
    $person = [
        "name" => "John",
        "age" => 25,
        "city" => "New York"
    ];
    
    // Access by key
    echo $person["name"];  // John
    echo $person["age"];  // 25
    echo $person["city"]; // New York
?>
```

### Adding Elements

```php
<?php
    $person = ["name" => "John", "age" => 25];
    
    // Add new key-value pair
    $person["email"] = "john@example.com";
    
    // Modify existing
    $person["age"] = 26;
    
    print_r($person);
?>
```

```warn header="Keys must be unique"
In associative arrays, each key can only appear once. If you assign a value to an existing key, it will overwrite the previous value:

```php
<?php
    $person = ["name" => "John"];
    $person["name"] = "Jane";  // Overwrites "John"
    echo $person["name"];  // Jane
?>
```

## Array Functions

PHP has many built-in functions for working with arrays.

### count() - Get Array Length

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    echo count($fruits);  // 3
    
    $person = ["name" => "John", "age" => 25];
    echo count($person);  // 2
?>
```

### print_r() and var_dump() - Display Arrays

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    
    // print_r - readable format
    print_r($fruits);
    // Output:
    // Array
    // (
    //     [0] => Apple
    //     [1] => Orange
    //     [2] => Banana
    // )
    
    // var_dump - detailed info
    var_dump($fruits);
    // Shows type and length info
?>
```

### in_array() - Check if Value Exists

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    
    if (in_array("Apple", $fruits)) {
        echo "Apple is in the array";
    }
    
    // Check with strict comparison
    if (in_array("apple", $fruits, true)) {
        echo "Found";  // Won't print (case-sensitive)
    }
?>
```

### array_key_exists() - Check if Key Exists

```php
<?php
    $person = ["name" => "John", "age" => 25];
    
    if (array_key_exists("name", $person)) {
        echo "Name key exists";
    }
    
    if (array_key_exists("email", $person)) {
        echo "This won't print";
    } else {
        echo "Email key doesn't exist";
    }
?>
```

## Adding and Removing Elements

### Adding Elements

```php
<?php
    $fruits = ["Apple", "Orange"];
    
    // Add to end
    array_push($fruits, "Banana", "Grape");
    // Or simply:
    $fruits[] = "Mango";
    
    // Add to beginning
    array_unshift($fruits, "Kiwi");
?>
```

### Removing Elements

```php
<?php
    $fruits = ["Apple", "Orange", "Banana", "Grape"];
    
    // Remove last element (returns the removed value)
    $last = array_pop($fruits);  // $last = "Grape"
    
    // Remove first element (returns the removed value)
    $first = array_shift($fruits);  // $first = "Apple"
    
    // Remove by index (use unset)
    unset($fruits[1]);  // Removes element at index 1
    
    // Note: unset leaves gaps in indexed arrays
    // Use array_values() to reindex
    $fruits = array_values($fruits);
?>
```

```warn header="unset() leaves gaps in indexed arrays"
When you use `unset()` on an indexed array, it removes the element but doesn't renumber the indices:

```php
<?php
    $arr = ["a", "b", "c"];
    unset($arr[1]);
    // Array is now: [0 => "a", 2 => "c"]
    // Notice: index 1 is missing!
    
    // To fix, use array_values()
    $arr = array_values($arr);
    // Now: [0 => "a", 1 => "c"]
?>
```

## Looping Through Arrays

### foreach Loop (Most Common)

```php
<?php
    // Indexed array
    $fruits = ["Apple", "Orange", "Banana"];
    
    foreach ($fruits as $fruit) {
        echo $fruit . "<br>";
    }
    // Output:
    // Apple
    // Orange
    // Banana
    
    // Associative array
    $person = ["name" => "John", "age" => 25, "city" => "New York"];
    
    foreach ($person as $key => $value) {
        echo "$key: $value<br>";
    }
    // Output:
    // name: John
    // age: 25
    // city: New York
?>
```

### for Loop

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    
    for ($i = 0; $i < count($fruits); $i++) {
        echo $fruits[$i] . "<br>";
    }
?>
```

### while Loop

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    $i = 0;
    
    while ($i < count($fruits)) {
        echo $fruits[$i] . "<br>";
        $i++;
    }
?>
```

```smart header="foreach is preferred"
For arrays, `foreach` is usually the best choice because:
- It's simpler and cleaner
- Works with both indexed and associative arrays
- Automatically handles the iteration
- No need to manage index counters
```

## Multidimensional Arrays

Arrays can contain other arrays, creating multidimensional arrays.

### Two-Dimensional Array

```php
<?php
    // Array of arrays
    $students = [
        ["name" => "John", "age" => 20, "grade" => "A"],
        ["name" => "Jane", "age" => 21, "grade" => "B"],
        ["name" => "Bob", "age" => 19, "grade" => "A"]
    ];
    
    // Access elements
    echo $students[0]["name"];  // John
    echo $students[1]["age"];   // 21
    
    // Loop through
    foreach ($students as $student) {
        echo $student["name"] . " - " . $student["grade"] . "<br>";
    }
?>
```

### Indexed Multidimensional Array

```php
<?php
    $matrix = [
        [1, 2, 3],
        [4, 5, 6],
        [7, 8, 9]
    ];
    
    echo $matrix[0][1];  // 2
    echo $matrix[2][2];  // 9
    
    // Loop through
    foreach ($matrix as $row) {
        foreach ($row as $cell) {
            echo $cell . " ";
        }
        echo "<br>";
    }
?>
```

## Common Array Operations

### Sorting Arrays

```php
<?php
    $fruits = ["Orange", "Apple", "Banana"];
    
    // Sort indexed array (modifies original)
    sort($fruits);  // ["Apple", "Banana", "Orange"]
    
    // Reverse sort
    rsort($fruits);  // ["Orange", "Banana", "Apple"]
    
    // Sort associative array by value
    $person = ["name" => "John", "age" => 25, "city" => "New York"];
    asort($person);  // Sorts by value, keeps keys
    
    // Sort associative array by key
    ksort($person);  // Sorts by key
?>
```

### Merging Arrays

```php
<?php
    $arr1 = ["Apple", "Orange"];
    $arr2 = ["Banana", "Grape"];
    
    // Merge arrays
    $merged = array_merge($arr1, $arr2);
    // ["Apple", "Orange", "Banana", "Grape"]
    
    // Or using spread operator (PHP 7.4+)
    $merged = [...$arr1, ...$arr2];
?>
```

### Searching Arrays

```php
<?php
    $fruits = ["Apple", "Orange", "Banana"];
    
    // Find key of value
    $key = array_search("Orange", $fruits);
    echo $key;  // 1
    
    // Check if key exists (associative)
    $person = ["name" => "John", "age" => 25];
    if (isset($person["name"])) {
        echo "Name exists";
    }
?>
```

### Extracting Keys and Values

```php
<?php
    $person = ["name" => "John", "age" => 25, "city" => "New York"];
    
    // Get all keys
    $keys = array_keys($person);
    // ["name", "age", "city"]
    
    // Get all values
    $values = array_values($person);
    // ["John", 25, "New York"]
?>
```

## Array vs JavaScript Comparison

| Feature | PHP | JavaScript |
|---------|-----|------------|
| **Create** | `$arr = [1, 2, 3]` | `let arr = [1, 2, 3]` |
| **Access** | `$arr[0]` | `arr[0]` |
| **Length** | `count($arr)` | `arr.length` |
| **Add end** | `$arr[] = 4` or `array_push()` | `arr.push(4)` |
| **Remove end** | `array_pop($arr)` | `arr.pop()` |
| **Loop** | `foreach ($arr as $item)` | `for (let item of arr)` |
| **Associative** | Native support | Use objects `{}` |

```php
<?php
    // PHP: Arrays can be indexed or associative
    $indexed = [1, 2, 3];
    $associative = ["name" => "John", "age" => 25];
?>
```

```javascript
// JavaScript: Arrays are indexed, objects are associative
let indexed = [1, 2, 3];
let associative = {name: "John", age: 25};
```

## Practical Examples

### Example 1: Shopping Cart

```php
<?php
    $cart = [];
    
    // Add items
    $cart[] = ["item" => "Apple", "price" => 1.50, "qty" => 3];
    $cart[] = ["item" => "Orange", "price" => 2.00, "qty" => 2];
    
    // Calculate total
    $total = 0;
    foreach ($cart as $item) {
        $subtotal = $item["price"] * $item["qty"];
        $total += $subtotal;
        echo $item["item"] . ": $" . $subtotal . "<br>";
    }
    echo "Total: $" . $total;
?>
```

### Example 2: Student Grades

```php
<?php
    $students = [
        "John" => [85, 90, 88],
        "Jane" => [92, 87, 95],
        "Bob" => [78, 82, 80]
    ];
    
    foreach ($students as $name => $grades) {
        $average = array_sum($grades) / count($grades);
        echo "$name: Average = " . round($average, 2) . "<br>";
    }
?>
```

### Example 3: Form Data Processing

```php
<?php
    // Simulating form data
    $formData = [
        "username" => "john_doe",
        "email" => "john@example.com",
        "interests" => ["coding", "reading", "gaming"]
    ];
    
    // Validate required fields
    $required = ["username", "email"];
    foreach ($required as $field) {
        if (!isset($formData[$field]) || empty($formData[$field])) {
            echo "Error: $field is required<br>";
        }
    }
    
    // Display interests
    if (isset($formData["interests"])) {
        echo "Interests: " . implode(", ", $formData["interests"]);
    }
?>
```

## Important Functions Reference

### Essential Array Functions

```php
<?php
    $arr = ["Apple", "Orange", "Banana"];
    
    // count() - Get length
    count($arr);  // 3
    
    // in_array() - Check if value exists
    in_array("Apple", $arr);  // true
    
    // array_search() - Find key of value
    array_search("Orange", $arr);  // 1
    
    // array_push() - Add to end
    array_push($arr, "Grape");
    
    // array_pop() - Remove from end
    array_pop($arr);
    
    // array_shift() - Remove from beginning
    array_shift($arr);
    
    // array_unshift() - Add to beginning
    array_unshift($arr, "Kiwi");
    
    // sort() - Sort array
    sort($arr);
    
    // array_merge() - Merge arrays
    $new = array_merge($arr, ["Mango"]);
    
    // array_keys() - Get all keys
    array_keys($arr);
    
    // array_values() - Get all values
    array_values($arr);
    
    // implode() - Join array to string
    implode(", ", $arr);  // "Apple, Orange, Banana"
    
    // explode() - Split string to array
    explode(", ", "Apple, Orange, Banana");
?>
```

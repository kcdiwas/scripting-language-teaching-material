# PHP Form Handling

Forms are how users send data to your PHP server. PHP can receive, validate, and process this data. This is essential for user registration, login, search, and more!

## How Forms Work with PHP

When a user submits a form, the data is sent to a PHP file. PHP receives it through special arrays:
* `$_GET` - for GET method (data in URL)
* `$_POST` - for POST method (data hidden from URL)
* `$_REQUEST` - contains both GET and POST data

## Basic Form Example

**HTML form (form.html):**
```html
<!DOCTYPE html>
<html>
<body>
  <form action="process.php" method="POST">
    <label>Name:</label>
    <input type="text" name="username">
    
    <label>Email:</label>
    <input type="email" name="email">
    
    <button type="submit">Submit</button>
  </form>
</body>
</html>
```

**PHP processor (process.php):**
```php
<?php
$username = $_POST['username'];
$email = $_POST['email'];

echo "Name: " . $username . "<br>";
echo "Email: " . $email;
?>
```

## GET vs POST Methods

**GET method:**
```html
<form action="search.php" method="GET">
  <input type="text" name="query">
  <button type="submit">Search</button>
</form>
```

```php
<?php
$query = $_GET['query'];
echo "You searched for: " . $query;
// URL will be: search.php?query=something
?>
```

**When to use GET:**
* Search forms
* Bookmarkable pages
* Data you want in URL
* Non-sensitive data

**POST method:**
```html
<form action="register.php" method="POST">
  <input type="text" name="username">
  <input type="password" name="password">
  <button type="submit">Register</button>
</form>
```

```php
<?php
$username = $_POST['username'];
$password = $_POST['password'];
// Data is NOT visible in URL
?>
```

**When to use POST:**
* Login/registration forms
* Sensitive data (passwords)
* Large amounts of data
* File uploads
* Data that modifies database

## Checking if Form was Submitted

**Check request method:**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  // Form was submitted
  $name = $_POST['name'];
  echo "Welcome, " . $name;
}
?>
```

**Check if value exists:**
```php
<?php
if (isset($_POST['submit'])) {
  // Form submitted
  $email = $_POST['email'];
  echo "Email: " . $email;
}
?>
```

**Combined HTML and PHP:**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $name = $_POST['name'];
  echo "<h2>Hello, " . htmlspecialchars($name) . "</h2>";
}
?>

<form method="POST" action="<?php echo $_SERVER['PHP_SELF']; ?>">
  <input type="text" name="name" required>
  <button type="submit">Submit</button>
</form>
```

## Form Validation

**Server-side validation is essential!** Never trust user input.

**Check for empty fields:**
```php
<?php
if ($_SERVER["REQUEST_METHOD"] == "POST") {
  $name = $_POST['name'];
  $email = $_POST['email'];
  
  $errors = [];
  
  // Check if empty
  if (empty($name)) {
    $errors[] = "Name is required";
  }
  
  if (empty($email)) {
    $errors[] = "Email is required";
  }
  
  if (empty($errors)) {
    echo "Form is valid!";
  } else {
    foreach ($errors as $error) {
      echo $error . "<br>";
    }
  }
}
?>
```

**Validate email:**
```php
<?php
$email = $_POST['email'];

if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
  echo "Invalid email format";
} else {
  echo "Valid email";
}
?>
```

**Validate length:**
```php
<?php
$username = $_POST['username'];

if (strlen($username) < 3) {
  echo "Username must be at least 3 characters";
} elseif (strlen($username) > 20) {
  echo "Username must be less than 20 characters";
} else {
  echo "Valid username";
}
?>
```

**Validate numbers:**
```php
<?php
$age = $_POST['age'];

if (!is_numeric($age)) {
  echo "Age must be a number";
} elseif ($age < 18) {
  echo "Must be 18 or older";
} else {
  echo "Valid age";
}
?>
```

## Security: Sanitize and Escape

**Always sanitize user input to prevent attacks!**

**Remove HTML tags:**
```php
<?php
$input = $_POST['comment'];
$clean = strip_tags($input); // removes HTML/PHP tags
?>
```

**Escape HTML special characters:**
```php
<?php
$input = $_POST['name'];
$safe = htmlspecialchars($input, ENT_QUOTES, 'UTF-8');
echo $safe; // safe to display
?>
```

**Sanitize string:**
```php
<?php
$input = $_POST['username'];
$clean = filter_var($input, FILTER_SANITIZE_STRING);
?>
```

**Sanitize email:**
```php
<?php
$email = $_POST['email'];
$clean = filter_var($email, FILTER_SANITIZE_EMAIL);
?>
```

**Sanitize URL:**
```php
<?php
$url = $_POST['website'];
$clean = filter_var($url, FILTER_SANITIZE_URL);
?>
```

## Complete Form Example

```php
<?php
$name = $email = $message = "";
$errors = [];
$success = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
  // Get and sanitize inputs
  $name = htmlspecialchars(trim($_POST['name']));
  $email = htmlspecialchars(trim($_POST['email']));
  $message = htmlspecialchars(trim($_POST['message']));
  
  // Validate name
  if (empty($name)) {
    $errors[] = "Name is required";
  } elseif (strlen($name) < 2) {
    $errors[] = "Name must be at least 2 characters";
  }
  
  // Validate email
  if (empty($email)) {
    $errors[] = "Email is required";
  } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
    $errors[] = "Invalid email format";
  }
  
  // Validate message
  if (empty($message)) {
    $errors[] = "Message is required";
  } elseif (strlen($message) < 10) {
    $errors[] = "Message must be at least 10 characters";
  }
  
  // If no errors, process form
  if (empty($errors)) {
    // Process the data (save to database, send email, etc.)
    $success = "Form submitted successfully!";
    // Reset form
    $name = $email = $message = "";
  }
}
?>

<!DOCTYPE html>
<html>
<body>
  <h2>Contact Form</h2>
  
  <?php if (!empty($errors)): ?>
    <div style="color: red;">
      <?php foreach ($errors as $error): ?>
        <p><?php echo $error; ?></p>
      <?php endforeach; ?>
    </div>
  <?php endif; ?>
  
  <?php if (!empty($success)): ?>
    <div style="color: green;">
      <p><?php echo $success; ?></p>
    </div>
  <?php endif; ?>
  
  <form method="POST" action="<?php echo htmlspecialchars($_SERVER['PHP_SELF']); ?>">
    <div>
      <label>Name:</label><br>
      <input type="text" name="name" value="<?php echo $name; ?>">
    </div>
    
    <div>
      <label>Email:</label><br>
      <input type="email" name="email" value="<?php echo $email; ?>">
    </div>
    
    <div>
      <label>Message:</label><br>
      <textarea name="message"><?php echo $message; ?></textarea>
    </div>
    
    <button type="submit">Submit</button>
  </form>
</body>
</html>
```

## File Uploads

**HTML form (must have enctype):**
```html
<form method="POST" enctype="multipart/form-data">
  <input type="file" name="fileToUpload">
  <button type="submit">Upload</button>
</form>
```

**PHP handling:**
```php
<?php
if (isset($_FILES['fileToUpload'])) {
  $file = $_FILES['fileToUpload'];
  
  $fileName = $file['name'];
  $fileTmpName = $file['tmp_name'];
  $fileSize = $file['size'];
  $fileError = $file['error'];
  
  // Check for errors
  if ($fileError === 0) {
    // Check file size (5MB limit)
    if ($fileSize < 5000000) {
      $uploadPath = "uploads/" . $fileName;
      move_uploaded_file($fileTmpName, $uploadPath);
      echo "File uploaded successfully!";
    } else {
      echo "File is too large";
    }
  } else {
    echo "Error uploading file";
  }
}
?>
```

## Quick Recap

**Receiving form data:**
* `$_GET['name']` - GET method data
* `$_POST['name']` - POST method data
* `$_REQUEST['name']` - both GET and POST

**Validation:**
* Check if empty: `empty($var)`
* Check if set: `isset($var)`
* Validate email: `filter_var($email, FILTER_VALIDATE_EMAIL)`
* Check length: `strlen($var)`
* Check numeric: `is_numeric($var)`

**Security (ALWAYS do this!):**
* `htmlspecialchars()` - escape HTML
* `strip_tags()` - remove HTML tags
* `filter_var()` - sanitize inputs
* `trim()` - remove whitespace
* Never trust user input!

**Best practices:**
* Always validate on server-side
* Sanitize all user input
* Use POST for sensitive data
* Show clear error messages
* Keep submitted values after validation errors
* Use `$_SERVER['PHP_SELF']` for form action
* Always escape output with `htmlspecialchars()`

Form handling is the foundation of interactive PHP applications. Handle it securely!

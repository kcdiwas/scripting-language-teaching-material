# JavaScript Fundamentals

JavaScript is the language that makes web pages interactive.

HTML gives a page structure. CSS gives it style. JavaScript gives it behavior.

When you click a button, show a message, check a form, change text, or open a menu, JavaScript is usually doing the work behind the scenes.

## Introduction

JavaScript is a programming language used mainly on web pages.

It helps you:
- Respond to user actions like clicks and keyboard input
- Change page content without reloading the page
- Validate forms before sending them
- Create interactive features like sliders, menus, and popups

JavaScript runs inside the browser, so it can work directly with the page the user is seeing.

## Need of Client Side Scripting Language

A **client-side scripting language** runs on the user's device, usually inside the browser.

JavaScript is important on the client side because it can:
- Make pages faster by handling simple tasks in the browser
- Reduce server work by checking input before sending it
- Improve user experience by giving instant feedback
- Change page content without waiting for a full page reload

For example, if a user types a wrong email address, JavaScript can show a warning immediately.

Without client-side scripting, every small action would need to go to the server. That would be slower and less convenient.

```smart header="Client side vs server side"
Client side means the code runs in the browser on the user's device.

Server side means the code runs on the web server.

JavaScript is often used on both sides today, but in web pages it is mainly used as a client-side language.
```

## Formatting and Coding Conventions

Good code is not just code that works. It should also be easy to read.

Some simple JavaScript conventions are:

- Use meaningful names
- Keep indentation consistent
- Put spaces around operators
- End statements with semicolons if your course or project follows that style
- Write short, clear lines
- Use braces `{}` for blocks

Example of neat formatting:

```js
let userName = "Asha";

if (userName) {
  alert("Hello, " + userName);
}
```

Example of poor formatting:

```js
let userName="Asha"
if(userName){alert("Hello, "+userName)}
```

Both examples may work, but the first one is much easier to understand.

```smart header="Why conventions matter"
When code is clean and consistent:
- You understand it faster
- Your classmates can read it more easily
- Debugging becomes simpler
- Large programs are easier to maintain
```

## JavaScript Files

You do not have to write JavaScript directly inside HTML every time.

You can place JavaScript in a separate file, usually with the `.js` extension.

Example:

```txt
index.html
script.js
style.css
```

Example `script.js`:

```js
function greet() {
  alert("Hello!");
}
```

Advantages of separate JavaScript files:
- Cleaner HTML
- Easier reuse
- Easier maintenance
- Better organization for bigger projects

When the same script is used on multiple pages, a separate file is especially useful.

## Comments

Comments are notes inside code that the browser ignores.

They help you explain your code to yourself and others.

### Single-line comments

Use `//` for a short comment:

```js
// This shows a greeting
alert("Hello");
```

### Multi-line comments

Use `/* ... */` for longer comments:

```js
/*
  This function shows
  a welcome message.
*/
function welcome() {
  alert("Welcome!");
}
```

Comments are useful for:
- Explaining tricky code
- Marking important sections
- Temporarily hiding code while testing

Do not overuse comments for things that are already obvious from the code.

## Embedding JavaScript in HTML

There are two common ways to use JavaScript in an HTML page:
- Write it inside the HTML file
- Link an external `.js` file

Inline JavaScript is usually used for small examples or quick practice.

```html
<!DOCTYPE html>
<html>
<head>
  <title>My Page</title>
</head>
<body>
  <button onclick="alert('Hello!')">Click me</button>
</body>
</html>
```

In real projects, it is better to keep most JavaScript in separate files.

## Using Script Tag

The `<script>` tag is used to add JavaScript to a web page.

### Writing JavaScript inside the page

```html
<!DOCTYPE html>
<html>
<head>
  <title>Script Example</title>
</head>
<body>
  <h1>JavaScript Demo</h1>

  <script>
    alert("JavaScript is running!");
  </script>
</body>
</html>
```

### Linking an external file

```html
<!DOCTYPE html>
<html>
<head>
  <title>External Script</title>
  <script src="script.js"></script>
</head>
<body>
  <h1>External JavaScript</h1>
</body>
</html>
```

You can also place the `<script>` tag near the end of the `<body>` element so the HTML loads first.

That is often helpful when your script needs to work with page elements.

```smart header="Why place script near the end"
If JavaScript tries to use an element before the browser has created that element, it may fail.

Placing the script near the end of the body helps the page load its content first.
```

## NoScript Tag

The `<noscript>` tag is shown only when JavaScript is turned off or not supported.

This is useful for giving a message to users who cannot run JavaScript.

```html
<!DOCTYPE html>
<html>
<head>
  <title>NoScript Example</title>
</head>
<body>
  <h1>Welcome</h1>

  <noscript>
    <p>Your browser does not support JavaScript or JavaScript is turned off.</p>
  </noscript>
</body>
</html>
```

If JavaScript is enabled, the content inside `<noscript>` is ignored.

## Data Types

JavaScript values have different data types. A data type tells you what kind of value something is.

The most common basic types are:

- `number` - for numeric values like `10`, `3.5`, or `100`
- `string` - for text values like `"Hello"` or `'Asha'`
- `boolean` - for `true` or `false`
- `undefined` - when a variable has been declared but not given a value
- `null` - used to show that a variable is intentionally empty

Example:

```js
let age = 20;          // number
let name = "Ravi";     // string
let isStudent = true;  // boolean
let value;             // undefined
let empty = null;      // null
```

### Using typeof

You can use `typeof` to check the type of a value.

```js
let price = 99.5;
alert(typeof price); // number

let city = "Kathmandu";
alert(typeof city); // string
```

### Simple rules to remember

- Put quotes around strings
- Do not put quotes around numbers or booleans
- Use `true` and `false` for boolean values
- `undefined` usually means "not assigned yet"
- `null` usually means "intentionally empty"

```smart header="Important note"
`typeof null` returns `"object"` in JavaScript. This is a known quirk of the language.
```

## Operators

Operators are symbols that tell JavaScript to do something with values.

### Arithmetic operators

These are used for math:

- `+` addition
- `-` subtraction
- `*` multiplication
- `/` division
- `%` remainder

Example:

```js
let a = 10;
let b = 3;

alert(a + b); // 13
alert(a % b); // 1
```

### Assignment operators

Assignment operators store values in variables.

```js
let x = 5;
x += 2; // same as x = x + 2
```

### Comparison operators

These compare values and return `true` or `false`.

- `==` equal to
- `===` strictly equal to
- `!=` not equal to
- `!==` strictly not equal to
- `>` greater than
- `<` less than
- `>=` greater than or equal to
- `<=` less than or equal to

Example:

```js
let age = 18;

alert(age >= 18); // true
```

### Logical operators

Logical operators combine conditions.

- `&&` means AND
- `||` means OR
- `!` means NOT

Example:

```js
let loggedIn = true;
let hasPermission = false;

alert(loggedIn && hasPermission); // false
```

### String operator

The `+` operator can join text together.

```js
let firstName = "Ravi";
let lastName = "Kumar";

alert(firstName + " " + lastName); // Ravi Kumar
```

## Control Structures

Control structures help your program decide what to do and repeat actions.

### if

Use `if` when you want to run code only if a condition is true.

```js
let marks = 75;

if (marks >= 40) {
  alert("Pass");
}
```

### if...else

Use `if...else` when you want two possible outcomes.

```js
let marks = 25;

if (marks >= 40) {
  alert("Pass");
} else {
  alert("Fail");
}
```

### else if

Use `else if` when there are more than two choices.

```js
let score = 82;

if (score >= 90) {
  alert("A grade");
} else if (score >= 75) {
  alert("B grade");
} else {
  alert("Needs improvement");
}
```

### switch

Use `switch` when one value can match several cases.

```js
let day = 3;

switch (day) {
  case 1:
    alert("Monday");
    break;
  case 2:
    alert("Tuesday");
    break;
  case 3:
    alert("Wednesday");
    break;
  default:
    alert("Other day");
}
```

### while loop

Use `while` to repeat code while a condition is true.

```js
let count = 1;

while (count <= 3) {
  alert(count);
  count++;
}
```

### for loop

Use `for` when you know how many times you want to repeat something.

```js
for (let i = 1; i <= 3; i++) {
  alert(i);
}
```

```smart header="Think before looping"
Loops are great for repeated work.

But if you need to repeat something only once, do not use a loop just because it looks advanced.
```

JavaScript helps web pages become interactive and useful.

Key points:

- Comments help explain code
- The `<script>` tag adds JavaScript to a page
- The `<noscript>` tag shows a message when JavaScript is unavailable
- Operators help you calculate, compare, and combine values
- Control structures help your program make decisions and repeat actions

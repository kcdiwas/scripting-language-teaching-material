# JavaScript Fundamentals Practice Problems

## Problem 1: Introduction to JavaScript
Write a simple HTML page with:
- A heading
- A paragraph
- A button that shows an alert when clicked

The alert should say: `JavaScript is working!`

**Hint:** Use the `onclick` attribute or a `<script>` tag.

---

## Problem 2: Client Side Scripting
Write a short answer in your own words:
1. What is a client-side scripting language?
2. Why is JavaScript useful on the client side?
3. Give one example of a task that JavaScript can do in the browser

**Expected answer style:** Simple sentences, not long paragraphs.

---

## Problem 3: Formatting Practice
Fix the formatting of this code so it becomes easy to read:

```js
let name="Sara"
if(name){alert("Hello,"+name)}
```

**Your task:**
1. Add proper spacing
2. Put the code in a readable block
3. Keep the meaning the same

**Hint:** Clean code is easier to understand than squeezed code.

---

## Problem 4: JavaScript File and Comments
Create:
- One HTML file
- One external JavaScript file

The JavaScript file should:
1. Show an alert
2. Include one single-line comment
3. Include one multi-line comment

**Hint:** Link the file using `<script src="..."></script>`.

---

## Problem 5: Script Tag and NoScript Tag
Write an HTML page that:
1. Uses a `<script>` tag to show a welcome message
2. Uses a `<noscript>` tag to show a message if JavaScript is off

**Expected behavior:**
- If JavaScript is enabled, the script message should run
- If JavaScript is disabled, the `<noscript>` message should appear

**Hint:** The `<noscript>` content is only visible when JavaScript is not available.

---

## Problem 6: Operators Practice
Write JavaScript code that:
1. Stores two numbers in variables
2. Shows the result of addition, subtraction, multiplication, and division
3. Checks whether the first number is greater than the second
4. Combines two words into one full name

**Test values:**
```js
let a = 12;
let b = 4;
```

**Expected output ideas:**
- `16`
- `8`
- `48`
- `3`
- `true` or `false`
- A full name made from two strings

---

## Problem 7: Control Structures Practice
Write JavaScript code for each case:

1. If a number is positive, show `"Positive"`
2. If it is negative, show `"Negative"`
3. If it is zero, show `"Zero"`

Then write another example using a `for` loop to show numbers from 1 to 5.

**Hint:** Use `if...else if...else` for the first part and `for` for the second part.

---

## Bonus Challenge
Create a small page that:
- Asks for a user name
- Checks if the name is empty
- If the name is filled in, shows a welcome message
- If the name is empty, shows a warning message

**Extra challenge:** Put the JavaScript in an external file and add a comment above each important step.

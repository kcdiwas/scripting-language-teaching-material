# WordPress Notes (Administrator Level)

Here are your exam-focused notes on **WordPress** at the **Administrator level** — Theme Integration, Creating Pages, Managing Posts, and Managing Widgets.

---

### **1. What is WordPress?**

**WordPress** is the world's most popular **CMS (Content Management System)**, built with **PHP** and **MySQL**.

* **Free and open-source**; started in 2003 as a blogging tool.
* Powers a huge share of all websites on the internet.
* **Motto:** "Code is Poetry."
* Known for being the **easiest CMS to use** — you can build a site without coding.

**Two versions (don't confuse them):**

| Version | Meaning |
| --- | --- |
| **WordPress.org** | The **self-hosted** software you install on your own server (full control). |
| **WordPress.com** | A **hosting service** run by the company (limited control, easy start). |

*(Course/admin work uses **WordPress.org**.)*

---

### **2. The WordPress Dashboard (Admin Area)**

The **Dashboard** is the admin control panel. You log in at:

```
http://yoursite.com/wp-admin
```

**Main menu items on the left:**

| Menu | What it does |
| --- | --- |
| **Posts** | Blog articles (time-based, use categories & tags). |
| **Pages** | Static content (About, Contact). |
| **Media** | Library of uploaded images, videos, files. |
| **Appearance** | **Themes, Widgets, Menus, Customizer.** |
| **Plugins** | Add-ons for extra features. |
| **Users** | Manage accounts and roles. |
| **Settings** | Site title, permalinks, reading/writing options. |

---

### **3. Posts vs Pages (Very Important Exam Point)**

Students often mix these up. Know the difference clearly.

| Feature | **Posts** | **Pages** |
| --- | --- | --- |
| **Type of content** | Dynamic / time-based | Static / timeless |
| **Examples** | News, blogs, articles | About Us, Contact, Privacy Policy |
| **Order** | Newest first (by date) | No date order |
| **Categories & Tags** | ✅ Yes | ❌ No |
| **Appears in RSS feed** | ✅ Yes | ❌ No |
| **Comments** | Usually on | Usually off |

---

### **4. Managing Posts**

A **Post** is a blog article. Posts are organized using **Categories** (broad groups) and **Tags** (specific keywords).

**To create a post:**

1. Go to **Posts → Add New**.
2. Enter a **Title**.
3. Write content in the **Editor** (the block editor called **Gutenberg**).
4. Set a **Category** and add **Tags** on the right.
5. Add a **Featured Image** (the main thumbnail).
6. Click **Publish** (or **Save Draft**, or **Schedule** for later).

**Post statuses:**

| Status | Meaning |
| --- | --- |
| **Draft** | Saved but not public. |
| **Published** | Live and visible to everyone. |
| **Scheduled** | Set to go live at a future date/time. |
| **Pending Review** | Waiting for an editor to approve. |
| **Private** | Visible only to logged-in admins/editors. |

**Categories vs Tags:**

* **Category** = the *chapter* of a book (e.g. "Sports"). Required, hierarchical.
* **Tag** = the *index keyword* (e.g. "cricket", "world-cup"). Optional, not hierarchical.

---

### **5. Creating Pages**

A **Page** is static content that does **not** change often (e.g. About, Contact).

**To create a page:**

1. Go to **Pages → Add New**.
2. Enter a **Title** (e.g. "About Us").
3. Add content using the block editor.
4. Set page options on the right:
   * **Parent Page** → to make a *sub-page* (creates a hierarchy, e.g. Services → Web Design).
   * **Template** → choose a special layout (Full Width, No Sidebar) if the theme provides one.
   * **Order** → number to control the display sequence.
5. Click **Publish**.

**Key difference:** Pages can have **parent/child hierarchy**; posts cannot.

---

### **6. Theme Integration**

A **Theme** controls the **design, layout, colours, and fonts** of the whole website — it's the "skin" of your WordPress site.

**Ways to add/integrate a theme:**

1. **Appearance → Themes → Add New**.
2. **Search & Install** from the free theme directory, **OR** **Upload** a theme `.zip` file.
3. Click **Activate** to make it live.
4. Click **Customize** to adjust it (logo, colours, homepage, menus) using the **Customizer** — you see a **live preview** as you edit.

**Important theme files (PHP templates):**

| File | Purpose |
| --- | --- |
| **`style.css`** | Theme's main stylesheet + theme info header (required). |
| **`index.php`** | The main/fallback template file (required). |
| **`header.php`** | Top of every page (logo, menu). |
| **`footer.php`** | Bottom of every page. |
| **`functions.php`** | Adds features & registers menus/widgets. |
| **`single.php`** | Layout for a single **post**. |
| **`page.php`** | Layout for a single **page**. |

**Parent vs Child theme:** A **child theme** inherits everything from a parent theme but lets you make changes safely **without losing them when the parent updates**.

---

### **7. Managing Widgets**

A **Widget** is a small block of content or a feature that you place in a **Widget Area** (also called a **Sidebar**) — for example the sidebar, header, or footer.

* Managed at **Appearance → Widgets**.
* You **drag & drop** a widget into a widget area (or use the block-based widget editor).

**Common built-in widgets:**

| Widget | Shows |
| --- | --- |
| **Search** | A search box. |
| **Recent Posts** | List of newest posts. |
| **Categories** | List of post categories. |
| **Recent Comments** | Latest visitor comments. |
| **Archives** | Posts grouped by month. |
| **Navigation Menu** | A custom menu. |
| **Custom HTML** | Your own HTML/ads code. |

**Key idea:** *Widgets add features to a widget area; the theme decides which widget areas exist.*

---

### **8. WordPress Extensibility: Themes vs Plugins**

Don't confuse these two ways of extending WordPress:

| | **Theme** | **Plugin** |
| --- | --- | --- |
| **Controls** | How the site **looks** (design). | What the site **does** (features). |
| **Example** | Layout, colours, fonts. | Contact form, SEO, security, shop. |
| **Managed under** | Appearance → Themes | Plugins |

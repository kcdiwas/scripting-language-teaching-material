# Joomla Notes

Here are your exam-focused notes on **Joomla** (a CMS built with PHP + MySQL).

---

### **1. What is a CMS?**

**CMS** stands for **C**ontent **M**anagement **S**ystem.

* **The Main Goal:** It lets you **build and manage a website without writing code** from scratch.
* **Key Feature:** Content (text, images, pages) is stored in a **database** and shown using **templates**.
* **Who uses it:** People who are *not* programmers — bloggers, shops, schools, offices.

**Analogy:**
Think of a CMS like **Microsoft Word for websites**.

* **Without a CMS:** You must hand-write every HTML page, upload it, and edit the code to change one word.
* **With a CMS:** You log in, click "Edit," type your text, and hit "Save." The system builds the page for you.

**Popular CMS examples:** WordPress, **Joomla**, Drupal.

---

### **2. What is Joomla?**

**Joomla** is a **free, open-source CMS** written in **PHP** that stores its data in a **MySQL** database.

* Released in 2005.
* Sits **between** WordPress (easiest) and Drupal (most technical) in difficulty.
* Great for **community sites, portals, and web applications** because it handles complex content and user management well.
* Built on the **MVC** design pattern (explained at the end).

---

### **3. Installation of Joomla**

Joomla needs a server that can run **PHP** and **MySQL**. On a local computer we use **XAMPP** (Apache + MySQL + PHP).

**Steps (Local Installation):**

1. **Install XAMPP** and start **Apache** and **MySQL** from the control panel.
2. **Download Joomla** from `joomla.org` (a `.zip` file).
3. **Extract** it into `C:\xampp\htdocs\joomla`.
4. **Create a database** in phpMyAdmin (`http://localhost/phpmyadmin`), e.g. `joomla_db`.
5. Open `http://localhost/joomla` in a browser to start the **Web Installer**.
6. Fill in three screens:
   * **Configuration:** Site name, admin username, password, email.
   * **Database:** Host = `localhost`, database name = `joomla_db`, user = `root`.
   * **Finalisation / Overview:** Click **Install**.
7. **Delete the `installation` folder** when prompted (required for security).

**Two URLs after install:**

| Part | URL | Meaning |
| --- | --- | --- |
| **Front End** | `http://localhost/joomla` | The public website visitors see. |
| **Back End** | `http://localhost/joomla/administrator` | The admin control panel. |

---

### **4. Handling the Joomla Back End (Administrator Panel)**

The **Back End** is where the administrator controls everything. Log in at `.../administrator`.

**Main menu areas:**

| Menu | What it controls |
| --- | --- |
| **Content** | Articles, Categories, Featured Articles, Media (images). |
| **Menus** | Site navigation menus and menu items. |
| **Components** | Big feature blocks (Contacts, Banners, News Feeds). |
| **Extensions** | Install/manage Modules, Plugins, Templates, Languages. |
| **Users** | Manage user accounts, groups, and access levels. |
| **System** | Global Configuration (site settings, SEO, cache). |

**Key idea:** In Joomla, content lives in **Articles**, articles are grouped into **Categories**, and they are shown to visitors through **Menu Items**.

---

### **5. Customization in Joomla**

Customization means changing how the site **looks** and **behaves** without rebuilding it.

You can customize through:

1. **Global Configuration** (System → Setup): change site name, turn on **SEO-friendly URLs**, enable **caching**, set the default editor.
2. **Templates:** change the theme, colours, logo, and layout positions.
3. **Modules:** move blocks (menu, login, search) into different **positions** on the page.
4. **Menus:** decide what appears in the navigation and in what order.
5. **Extensions:** add new features (gallery, forms, e-commerce).

---

### **6. Introduction to Extensions**

**Extensions** are add-ons that give Joomla **extra features** — like apps you install on a phone.

There are **5 main types** of Joomla extensions:

| Extension | Purpose | Example |
| --- | --- | --- |
| **Component** | The **main body** of a page; a mini-application. | Contact form, Shopping cart |
| **Module** | Small **boxes** shown around the main content (positions). | Login box, Latest News, Menu |
| **Plugin** | Runs in the **background** on events (before/after content shows). | Spam filter, "read more" cutter |
| **Template** | Controls the **overall look/layout** of the site. | A theme / skin |
| **Language** | Adds **translations** so the site can be multilingual. | Nepali, Hindi pack |

**Memory trick:** **C-M-P-T-L** → **C**omponent, **M**odule, **P**lugin, **T**emplate, **L**anguage.

---

### **7. Installation and Uses of Extensions**

**How to install an extension:**

1. Download the extension `.zip` file (e.g. from the Joomla Extensions Directory, **JED**).
2. Go to **Extensions → Manage → Install** in the back end.
3. **Upload** the `.zip` (drag & drop) → Joomla installs it automatically.
4. Enable/configure it under its own menu (Components, or Extensions → Modules/Plugins).

**Uses of extensions:**

* Add a **contact form** or **photo gallery**.
* Turn the site into an **online shop** (e.g. VirtueMart).
* Improve **SEO**, add **security**, or create **image sliders**.
* Show **latest articles**, **login boxes**, or **social media** links.

---

### **8. Template Development in Joomla**

A **Template** decides the **layout, colours, and design** of the site — the "skin" that wraps around the content.

**Key files in a Joomla template folder:**

| File | Purpose |
| --- | --- |
| **`index.php`** | The main layout file — decides where content and modules go. |
| **`templateDetails.xml`** | Describes the template (name, author, files, **module positions**). |
| **`css/` folder** | Stylesheets that control colours and fonts. |
| **`images/` folder** | Logo and design images. |

**Module Positions:** Inside `index.php` you place tags like:

```php
<jdoc:include type="modules" name="position-7" />
```

This tells Joomla: *"Show any module assigned to `position-7` right here."* Common positions are `header`, `left`, `right`, `footer`.

The `<jdoc:include>` tag is special — it pulls in dynamic parts:

* `type="component"` → the main article/page content.
* `type="modules"` → module boxes.
* `type="head"` → CSS/JS links in the `<head>`.

---

### **9. Artisteer (Template IDE)**

**Artisteer** is a **desktop software (IDE)** used to **design Joomla templates visually** — without writing HTML/CSS by hand.

* **Drag-and-drop** design of header, menu, colours, and layout.
* It **exports** a ready-to-install Joomla template `.zip`.
* Great for **beginners** who want a professional template quickly.
* Also supports WordPress, Drupal, and plain HTML themes.

**In short:** Artisteer = *"design your template by clicking, and it writes the code for you."*

---

### **10. Module Development in Joomla**

A **Module** is a small block (like Login or Latest News). To build a custom one, you create a folder `mod_hello` with these files:

| File | Purpose |
| --- | --- |
| **`mod_hello.php`** | Entry point; calls the helper and loads the layout. |
| **`helper.php`** | Contains the logic / gets the data. |
| **`mod_hello.xml`** | Manifest — name, files, and settings for installation. |
| **`tmpl/default.php`** | The layout (HTML) that displays the output. |

**Simple flow:** `mod_hello.php` → asks `helper.php` for data → sends it to `tmpl/default.php` → HTML is shown in a **module position**.

```php
// mod_hello.php (simplified)
<?php
require_once __DIR__ . '/helper.php';
$greeting = ModHelloHelper::getGreeting();      // get data from helper
require JModuleHelper::getLayoutPath('mod_hello'); // show default.php
?>
```

### **11. Component Development in Joomla**

A **Component** is the **biggest** extension — a full mini-application that fills the **main content area** of the page. It **strictly follows MVC**.

A component (e.g. `com_hello`) has **two sides**:

* **`site/`** → what visitors see (Front End).
* **`admin/`** → the management screens (Back End).

**Typical structure (MVC files):**

```
com_hello/
├── hello.php            (entry point / controller loader)
├── controller.php       (Controller - handles requests)
├── models/hello.php     (Model - talks to the database)
├── views/hello/view.html.php  (View - prepares data)
└── views/hello/tmpl/default.php (Template - the HTML output)
```

Components are accessed by URL, e.g. `index.php?option=com_hello`.

---

### **12. Introduction to MVC (Model – View – Controller)**

Joomla is built on the **MVC** software design pattern. It **separates code into 3 parts** so the project is organized and easy to maintain.

| Part | Job | Analogy (Restaurant) |
| --- | --- | --- |
| **Model** | Handles **data** — talks to the MySQL database (get, save, update). | The **Kitchen** (prepares the food/data). |
| **View** | Handles the **display** — turns data into HTML the user sees. | The **Plate/Presentation** (how food is served). |
| **Controller** | Handles the **logic** — takes the user's request and decides what to do. | The **Waiter** (takes your order, connects you to the kitchen). |

**Flow:** User request → **Controller** → asks **Model** for data → passes it to **View** → HTML shown to user.

**Why MVC is good:**

1. **Organized:** Design, data, and logic are kept separate.
2. **Reusable:** The same model can feed different views.
3. **Team-friendly:** A designer edits the View while a coder edits the Model.

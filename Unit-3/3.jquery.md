#  jQuery Notes

### **1. What is jQuery?**

jQuery is a lightweight **JavaScript Library**.

* **Motto:** "Write Less, Do More."
* **Purpose:** It makes writing JavaScript much shorter and easier. It handles HTML manipulation, events, and animation.
* **The `$ ` Sign:** This is the shortcut to access jQuery.

**Basic Syntax:**

```javascript
$(selector).action();

```

* `$`: Define jQuery.
* `(selector)`: "Query" or find HTML elements (like CSS).
* `.action()`: What to do to the element.

**Important:** Always wrap your code in the **Document Ready** function so it runs only after the page loads.

```javascript
$(document).ready(function(){
   // Your code here
});

```

---

## 2. Playing with Elements (DOM Manipulation)

You can easily "Get" (read) or "Set" (change) content on a webpage.

### **Common Methods**

| Method | Description | Example (Get) | Example (Set) |
| --- | --- | --- | --- |
| **`text()`** | Text inside an element. | `val = $("p").text();` | `$("p").text("Hello!");` |
| **`html()`** | Text + HTML tags inside. | `val = $("div").html();` | `$("div").html("<b>Bold</b>");` |
| **`val()`** | Value of form inputs. | `val = $("input").val();` | `$("input").val("New Value");` |
| **`attr()`** | Attributes (src, href, etc). | `val = $("img").attr("src");` | `$("img").attr("src", "pic.jpg");` |
| **`css()`** | Change CSS styles. | `val = $("p").css("color");` | `$("p").css("color", "red");` |

**Example: Changing Text on Click**

```html
<p id="msg">Old Text</p>
<button id="btn">Change Me</button>

<script>
$(document).ready(function(){
  $("#btn").click(function(){
    $("#msg").text("New Text!");
    $("#msg").css("color", "blue");
  });
});
</script>

```

## 3. Hiding and Unhiding Images (Effects)

jQuery makes animations very simple. You don't need complex CSS keyframes.

### **Key Methods**

1. **`hide()`**: Makes the element disappear (`display: none`).
2. **`show()`**: Makes it appear.
3. **`toggle()`**: Switches between hide and show.
4. **`fadeIn()` / `fadeOut()**`: Smoother transition using opacity.
5. **`slideUp()` / `slideDown()**`: Smoother transition using height.

**Example: Hiding/Showing an Image**

```html
<img id="myPic" src="cat.jpg" width="200">
<br>
<button id="hideBtn">Hide</button>
<button id="showBtn">Show</button>
<button id="toggleBtn">Toggle</button>

<script>
$(document).ready(function(){
  
  $("#hideBtn").click(function(){
    $("#myPic").hide(); // Disappear instantly
    // OR: $("#myPic").hide(1000); // Disappear over 1 second
  });

  $("#showBtn").click(function(){
    $("#myPic").show();
  });

  $("#toggleBtn").click(function(){
    $("#myPic").toggle(); // If hidden, show it. If visible, hide it.
  });

});
</script>

```

# 🎨 jQuery UI Notes

### **1. What is jQuery UI?**

**jQuery UI** (User Interface) is a **separate library** built *on top* of standard jQuery.

* It provides cool widgets (Datepickers, Sliders), interactions (Drag and Drop), and effects.
* **Important:** To use it, you must include **three** things in your HTML head:
1. jQuery Library (`jquery.js`)
2. jQuery UI Library (`jquery-ui.js`)
3. jQuery UI CSS (`jquery-ui.css`)



### **2. Common Exam Examples**

#### **A. Datepicker (Calendar)**

Instead of a boring text box for dates, jQuery UI gives you a popup calendar.

```html
<p>Date: <input type="text" id="datepicker"></p>

<script>
$(function() {
    $("#datepicker").datepicker();
});
</script>

```

#### **B. Draggable**

Allows the user to drag an element around the screen with their mouse.

```html
<div id="dragMe" style="width:100px; height:100px; background:red;">
  Drag me!
</div>

<script>
$(function() {
    $("#dragMe").draggable();
});
</script>

```

#### **C. Accordion**

Useful for FAQs. It creates expandable/collapsible sections.

```html
<div id="accordion">
  <h3>Section 1</h3>
  <div><p>Content for section 1.</p></div>
  <h3>Section 2</h3>
  <div><p>Content for section 2.</p></div>
</div>

<script>
$(function() {
    $("#accordion").accordion();
});
</script>

```

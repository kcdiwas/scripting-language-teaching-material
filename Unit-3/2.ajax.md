# AJAX & PHP Notes

### **1. What is AJAX?**

**AJAX** stands for **A**synchronous **J**ava**S**cript **A**nd **X**ML.

* **The Main Goal:** It allows a webpage to update **part of the content** without reloading the whole page.
* **Key Feature:** It talks to the server in the "background."
* **Not a Language:** AJAX is not a programming language itself; it's a technique using existing standards (JavaScript + XML/JSON + HTTP).

**Analogy:**
Imagine you are at a restaurant.

* **Without AJAX:** To get more water, you have to leave the table, go to the kitchen, get water, and come back (Page Reload).
* **With AJAX:** You wave at the waiter (JavaScript). The waiter goes to the kitchen (Server), gets the water, and brings it to you while you stay seated (No Reload).

---

### **2. How AJAX Works (The 4 Steps)**

1. **Event:** User clicks a button or types in a box.
2. **Request:** JavaScript creates an `XMLHttpRequest` object and sends data to a PHP file.
3. **Process:** The PHP file runs on the server (calculates math, checks database, etc.) and sends data back.
4. **Response:** JavaScript receives the data and updates the HTML.

### **3. Scenario 1: Using AJAX with PHP (No Database)**

*Goal: Send a name to the server, and the server says "Hello" back.*

**Frontend (HTML + JavaScript):**

```html
<!DOCTYPE html>
<html>
<body>

<h3>AJAX with PHP Example</h3>
<input type="text" id="nameInput" placeholder="Enter your name">
<button onclick="sendName()">Say Hello</button>
<p id="responseMessage"></p>

<script>
function sendName() {
    var name = document.getElementById("nameInput").value;

    // 1. Create the Object
    var xmlhttp = new XMLHttpRequest();

    // 2. Define what happens when the server responds
    xmlhttp.onreadystatechange = function() {
        if (this.readyState == 4 && this.status == 200) {
            // Update the paragraph with the response
            document.getElementById("responseMessage").innerHTML = this.responseText;
        }
    };

    // 3. Open the connection (Method, File, Asynchronous?)
    // sending name as a URL parameter
    xmlhttp.open("GET", "server_script.php?q=" + name, true);

    // 4. Send the request
    xmlhttp.send();
}
</script>

</body>
</html>

```

**Backend (server_script.php):**

```php
<?php
// Get the name from the URL parameter 'q'
$name = $_REQUEST["q"];

if ($name !== "") {
    echo "Hello, " . $name . "! Welcome to AJAX.";
} else {
    echo "Please enter a name.";
}
?>

```

### **4. Scenario 2: AJAX with PHP + MySQL 🗄️**

*Goal: Retrieve user details from a Database based on their ID without reloading the page.*

**Frontend (HTML + JavaScript):**

```html
<!DOCTYPE html>
<html>
<body>

<h3>Search User by ID</h3>
<input type="text" onkeyup="showUser(this.value)" placeholder="Enter User ID (e.g. 1)">
<div id="userInfo">User info will be listed here...</div>

<script>
function showUser(str) {
  if (str.length == 0) { 
    document.getElementById("userInfo").innerHTML = "";
    return;
  }
  
  var xmlhttp = new XMLHttpRequest();
  
  xmlhttp.onreadystatechange = function() {
    if (this.readyState == 4 && this.status == 200) {
      document.getElementById("userInfo").innerHTML = this.responseText;
    }
  };
  
  // Send the ID to the PHP file
  xmlhttp.open("GET", "get_user.php?id=" + str, true);
  xmlhttp.send();
}
</script>

</body>
</html>

```

**Backend (get_user.php):**

```php
<?php
// 1. Connect to DB
$conn = mysqli_connect("localhost", "root", "", "school_db");

// 2. Get the ID sent from JS
$id = $_REQUEST['id'];

// 3. Select data
$sql = "SELECT * FROM users WHERE id = '".$id."'";
$result = mysqli_query($conn, $sql);

// 4. Format the output (HTML Table)
if($row = mysqli_fetch_assoc($result)) {
    echo "<table border='1'>
    <tr>
        <th>ID</th>
        <th>Username</th>
    </tr>
    <tr>
        <td>" . $row['id'] . "</td>
        <td>" . $row['username'] . "</td>
    </tr>
    </table>";
} else {
    echo "No user found.";
}

mysqli_close($conn);
?>

```

### **5. Important Exam Keywords & Explanations**

| Term | Definition |
| --- | --- |
| **`XMLHttpRequest`** | The built-in JS object used to exchange data with a server. |
| **`onreadystatechange`** | A function (event listener) that triggers every time the status of the request changes. |
| **`readyState == 4`** | Means the request is **Done** and the response is ready. |
| **`status == 200`** | Means "OK" (The page was found and there were no server errors). |
| **`open(method, url, async)`** | Prepares the request. Usually `GET` or `POST`. `async` should be `true`. |
| **`send()`** | Actually sends the request to the server. |
| **`responseText`** | The data the server sent back (as a string). |

---

### **6. Why use AJAX? (Advantages)**

1. **Better User Experience:** No flashing screens or waiting for full reloads.
2. **Speed:** Reduces server traffic because you only send/receive the data needed, not the whole HTML page structure.
3. **Asynchronous:** The user can keep using the page while the data loads in the background.

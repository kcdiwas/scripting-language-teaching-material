#  PHP Object-Oriented Programming (OOP)

## 1. Classes and Objects

This is the foundation of OOP.

* **Class:** A **blueprint** or template. It defines the structure (variables and functions) but contains no actual data.
* **Object:** An **instance** of a class. It is the actual "thing" created from the blueprint. You can create many objects from one class.

**Exam Example:**

```php
<?php
// 1. Define the Class (Blueprint)
class Car {
    // Code goes here
}

// 2. Create Objects (Instances)
$bmw = new Car();
$toyota = new Car();
?>

```

---

## 2. Properties and Methods

Inside a class, we have two main things:

1. **Properties:** Variables inside a class (data).
2. **Methods:** Functions inside a class (actions).

**Key Syntax:**

* **`$this`**: A special variable used inside a class to refer to "this specific object".
* **`->`**: The arrow operator used to access properties and methods.

**Example:**

```php
class Student {
    // Property
    public $name;

    // Method
    function sayHello() {
        // Use $this to access the property
        return "Hello, I am " . $this->name; 
    }
}

$s1 = new Student();
$s1->name = "John"; // Setting property
echo $s1->sayHello(); // Calling method

```

## 3. Constructors and Destructors

Special methods that run automatically.

### **Constructor (`__construct`)**

* Runs **automatically** when an object is created (`new`).
* Used to initialize properties.
* **Note:** It starts with **two** underscores `__`.

### **Destructor (`__destruct`)**

* Runs **automatically** when the script ends or the object is deleted.
* Used for cleanup (closing database connections, saving files).

**Example:**

```php
class User {
    public $username;

    // Constructor
    function __construct($name) {
        $this->username = $name;
        echo "User $name created.<br>";
    }

    // Destructor
    function __destruct() {
        echo "User $this->username is leaving.<br>";
    }
}

$u = new User("Alice"); // Output: User Alice created.
// (At end of script) Output: User Alice is leaving.

```

## 4. Encapsulation (Access Modifiers)

Encapsulation is the practice of **hiding sensitive data** within the class to prevent outside interference. We control access using **Modifiers**.

| Modifier | Visibility | Who can access it? |
| --- | --- | --- |
| **`public`** | Everywhere | Inside class, Child class, Outside world. |
| **`protected`** | Family Only | Inside class & Child class. (Not Outside). |
| **`private`** | Self Only | Inside the class ONLY. |

**Exam Tip:** If a question asks "How to make a variable accessible only within the class?", the answer is `private`.

## 5. Inheritance

Inheritance allows a child class to acquire the properties and methods of a parent class.

* **Keyword:** `extends`
* **Purpose:** Code reusability (Don't write the same code twice).

**Example:**

```php
// Parent Class
class Animal {
    public function eat() {
        echo "I am eating.";
    }
}

// Child Class
class Dog extends Animal {
    public function bark() {
        echo "Woof!";
    }
}

$d = new Dog();
$d->eat();  // Inherited from Animal
$d->bark(); // Defined in Dog

```

---

## 6. Method Overriding

When a child class defines a method with the **same name** as the parent class to change its behavior.

**Example:**

```php
class Robot {
    public function greet() {
        echo "Beep boop.";
    }
}

class AdvancedRobot extends Robot {
    // Overriding the greet method
    public function greet() {
        echo "Hello, human!";
    }
}

$bot = new AdvancedRobot();
$bot->greet(); // Output: Hello, human!

```

## 7. Polymorphism

Polymorphism means "many forms". It allows different classes to use the same method name but behave differently. Usually implemented via Interfaces or Abstract Classes.

* **Concept:** You can treat a `Dog`, `Cat`, and `Cow` all as an `Animal` and call `$animal->makeSound()`, but each will produce a different sound.

**Example:**

```php
interface Animal {
    public function makeSound();
}

class Cat implements Animal {
    public function makeSound() { echo "Meow"; }
}

class Dog implements Animal {
    public function makeSound() { echo "Bark"; }
}

// $myPet can be a Cat or a Dog, the method name is the same.
$myPet = new Cat();
$myPet->makeSound(); 

```

## 8. Static Members (`static`)

Properties or methods that belong to the **Class itself**, not to any specific object.

* **Defining:** Use keyword `static`.
* **Accessing (Inside):** Use `self::` instead of `$this->`.
* **Accessing (Outside):** Use `ClassName::` (Double Colon).

**Example:**

```php
class MathHelper {
    public static $pi = 3.14;

    public static function add($a, $b) {
        return $a + $b;
    }
}

// No need to use 'new MathHelper()'
echo MathHelper::$pi; 
echo MathHelper::add(5, 10);

```

## 9. Exception Handling

How PHP handles runtime errors gracefully so the program doesn't crash completely.

* **`try`**: Block of code that might fail.
* **`throw`**: Triggers the error (Exception).
* **`catch`**: Catches the error and handles it.
* **`finally`**: (Optional) Code that runs regardless of success or failure.

**Example:**

```php
function divide($dividend, $divisor) {
    if ($divisor == 0) {
        throw new Exception("Cannot divide by zero!");
    }
    return $dividend / $divisor;
}

try {
    echo divide(10, 0); // This will fail
} catch (Exception $e) {
    echo "Error caught: " . $e->getMessage();
}

```

#  Exam "Cheat Sheet" Summary

| Concept | Keyword(s) | Symbol / Syntax |
| --- | --- | --- |
| **Class** | `class` | Blueprint |
| **Object** | `new` | `$obj = new Class();` |
| **This** | `$this` | `$this->variable` |
| **Inheritance** | `extends` | `class B extends A` |
| **Constructor** | `__construct` | Runs on `new` |
| **Static Access** | `self`, `static` | `::` (Scope Resolution Operator) |
| **Parent Access** | `parent` | `parent::__construct()` |
| **Object Access** | N/A | `->` (Arrow Operator) |

### **Common Student Mistakes (Watch out!)**

1. **The Dollar Sign:**
* *Wrong:* `$this->$name`
* *Right:* `$this->name` (No `$` after the arrow).


2. **Static vs Object:**
* Using `$this` inside a `static` function causes an error. Static functions don't know about objects!


3. **Constructors:**
* Forgetting the double underscore: `_construct` (Wrong) vs `__construct` (Right).
